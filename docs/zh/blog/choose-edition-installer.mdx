# 完整版、Mini、在线包和离线包怎么选？安装前检查这几项

先看电脑的系统和处理器，再决定功能与安装方式。Mini 的体积更小，但“更小”不等于“所有功能一样”，也不等于“下载以后永远不用联网”。这篇帮助你选到能安装、能完成所需任务的包，并用一次截图和文字识别检查准备是否完成。

## 第一步：确认系统和处理器

Windows 在**设置 → 系统 → 系统信息（关于）**查看系统类型，区分 x64 与 ARM64。Mac 在苹果菜单**关于本机**查看芯片或处理器：Apple 芯片选 arm64，Intel 选 x86_64。macOS 需要 **15 或更新版本**，Mini 不提供 Intel Mac 包。

![按 Windows 或 Mac 的处理器选择架构，再选择应用类型的流程](/images/blog/zh/installer-choice.svg)

*操作示意。先确认架构，再选完整版或 Mini，避免把不兼容问题误认为安装失败。*

打开[下载页](../download.mdx)，依次选择系统、处理器与应用。下载前再核对文件名中的 `windows-x64`、`windows-arm64`、`macos-arm64` 或 `macos-x86_64`。不要只凭文件体积挑选。

## 第二步：按要完成的任务选完整版或 Mini

| 需求 | 怎么选 |
| --- | --- |
| 截图、标注、贴图、拼图、录屏 | 完整版和 Mini 都包含这些基础工作流 |
| 手动识别普通文字 | Mini 可以使用，但需找到入口并准备 OCR 资源 |
| 表格、条码、公式、图片转换与翻译 | 选择完整版，再按具体功能准备模型或在线服务 |
| Intel Mac | 选择完整版 x86_64 包 |

Mini 中 OCR 可能默认不在截图工具栏；可从主窗口动作进入，或将**文本识别**加入工具栏。不能因为没看到图标就判断它完全不支持普通 OCR。反过来，本地 OCR 能用，也不能证明在线翻译和其他转换已经可用，见[OCR 排查](./ocr-troubleshooting.mdx)。

## 第三步：选安装方式，别把校验文件当安装包

Windows 常规使用可选匹配架构的在线安装包。即将去无网络环境且需要默认 OCR 资源时，选**完整版离线安装包**。Mini 没有 Windows 离线安装包；要离线用 OCR，先联网准备再实测。便携包要完整解压到可写目录，不能只从 ZIP 拖出主程序。

Mac 打开 DMG，将应用拖到**应用程序**，然后从应用程序目录启动。Apple 芯片可选 Full/Mini；Intel 选择 Full。普通手动安装不需要把 `-update.zip`、`.json`、`.sha256` 或 `-homebrew.tar.gz` 当作安装包打开。

![离线前分别完成安装、组件准备和实际识别的检查顺序](/images/blog/zh/offline-check.svg)

*操作示意。离线安装与离线任务准备是不同的检查点。*

## 第四步：首次启动后做两个小测试

1. 从托盘或 macOS 菜单栏图标打开主窗口，找到**截图**动作。新配置默认 Windows F1、macOS Control+1；没有反应时先点动作行，再按[快捷键排查](./shortcut-troubleshooting.mdx)检查绑定。
2. 截一块非敏感普通窗口，复制到文档或另存 PNG，确认画面和边界正常。macOS 按[权限说明](./macos-permissions.mdx)处理需要的项目。
3. 若要 OCR，识别两三行清晰文字，等组件准备结束，核对结果并复制。计划离线时，断网后重复这一个任务；普通截图成功不能代替识别测试。

![实际主窗口中显示截图动作与当前快捷键，首次启动可从这里测试](/images/blog/shortcuts-152.webp)

*操作截图。动作标题用于执行，右侧按键按钮用于配置；界面语言可在设置中调整。*

![截图动作标题和当前快捷键的局部视图](/images/blog/shortcut-action-detail-152.webp)

*操作截图局部。左侧标题执行截图，右侧按钮配置按键。*

需要其他大小的 OCR 模型或录屏组件时，也应提前在联网环境完成所需准备。不要把默认 OCR 资源齐全当作所有模型、录屏输入和在线服务都已齐全。

## 已安装但仍不对时

架构不兼容时回到系统信息重新核对；启动后版本号没变时，检查是否运行了旧便携目录或 DMG 内副本。安装包、便携目录、应用程序目录同时存在时，应先退出旧进程，再从目标位置启动。

更新前结束正在编辑或录制的任务并保存重要输出。官网下载版通过应用提示或官网下载页更新；应用商店或包管理器安装应沿用原渠道，避免不同副本混用。macOS 的自动检查不等于后台自动替换应用，具体行为见[安装与更新](../guides/getting-started/install.md)。

反馈安装问题时提供系统版本、处理器、Full/Mini、完整文件名、下载渠道和错误提示；识别问题另外提供模型与组件准备状态。[正式下载](../download.mdx) · [更新日志](../changelog.mdx) · [日志与存储](../guides/settings/storage-backup.md)。
