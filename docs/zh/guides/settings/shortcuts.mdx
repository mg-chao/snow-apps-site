# 快捷键与全局鼠标

全局快捷键让 Snow Shot 在其他应用前台时响应；应用快捷键只在对应编辑器或窗口里生效。全局鼠标则把「修饰键＋拖动」变成一次截图、识别、贴图或录屏操作。

![全局快捷键、应用内快捷键与全局鼠标三种作用范围](/images/guides/set-shortcuts.svg)

*操作示意。①跨应用入口，②当前工具内操作，③按住激活键拖动。*

## 修改全局快捷键

1. 打开主窗口「全局快捷键」，找到要执行的任务，例如截图、贴图、文字识别、录屏或打开历史。点击该行**右侧的按键配置按钮**，打开该动作的按键配置窗口。
2. 要替换已有绑定，点击显示原组合的**按键块**；要保留原绑定并增加备用组合，点击**添加按键配置**，进入新一行。每个全局动作最多有 **2 组**绑定，达到上限后不再显示添加按钮。
3. 看到**请按下按键**后，实际按下要使用的组合。录入期间，**Tab、Esc、Enter 也会被当作候选按键**，不会按通常方式切换焦点、取消窗口或确认保存；要放弃本次修改，用鼠标点击窗口的**取消**。
4. 检查按键块显示的候选组合。有效候选会让行末绿色勾和窗口**确定**按钮可用；出现冲突或不支持提示时，继续按另一个组合。重复占用的按键不能通过不断点击确定解决，必要时先释放另一个动作或应用的绑定。
5. 要继续添加或整理列表，先单击本行末尾的**绿色勾图标**结束录入。此时才可继续添加备用组合；尚在录入时，添加按钮不可用。结束录入后，行末变为**红色删除图标**，点击可从本次草稿中删除该行。
6. 检查整个列表，单击窗口底部的**确定**保存。只改一个有效组合时，也可不点行末勾，直接点外层确定，应用会一并确认当前候选。**只有外层确定才会保存绑定**，行末勾或删除图标都只修改本次草稿。
7. 不想保存时，点击**取消**或关闭这个配置窗口。即使已经点过行末勾、添加或删除过条目，也会舍弃整轮草稿，保留原配置。
8. 保存后返回列表，观察配置按钮的注册状态，再切到其他应用测试；取消后则检查列表仍显示原绑定。

想熟悉录入过程又保留现有快捷键，可以按下面的顺序练习，最后选择**取消**。示例暂时录入 Tab 作为候选，再放弃这次草稿。

配置窗口打开时会暂时释放相关全局按键，避免录入新组合时触发旧动作。完成配置并关闭窗口后，再测试实际调用。

|状态|含义与处理|
|---|---|
|已注册|系统接受了配置，可以实际调用检查|
|部分注册|多个配置中只有部分可用，查看提示区分可用与失败项|
|注册失败|查看冲突或系统拒绝原因，修改对应绑定|
|未配置|还没有可用绑定，进入配置窗口添加|
|暂时禁用|当前按键被主动释放，需要恢复启用或结束停用条件|

## 应用内快捷键与动作状态

打开「设置 → 应用快捷键」，按截图、标注、贴图、屏幕录制、图像识别分区修改。配置方法同样是点击动作的按键配置、按下组合、确认保存。

这些按键的作用还取决于当前窗口和编辑状态。例如录屏「开始/暂停/继续」根据录屏状态切换，标注快捷键在编辑区域使用；文本输入框获得焦点时，部分键会优先用于输入。当前工具按钮的提示会显示绑定，优先用它核对自己的配置。

Windows 还有「Windows 右键菜单」访问键，只接受不带修饰键的一个字母 A–Z 或数字 0–9；它用于经典右键菜单打开时选择项目，不是新的全局组合键。

## 配置全局鼠标拖动

1. 打开主窗口「全局鼠标」，找到希望完成的动作，例如「复制到剪贴板」或「固定到屏幕」，点击右侧鼠标配置按钮。
2. 在「激活按键」选择至少一个键。Windows 使用 Windows/Ctrl/Alt/Shift；macOS 使用 Command/Control/Option/Shift。
3. 在「鼠标按键」选择左键拖动、右键拖动、中键拖动、侧键 1（后退）拖动或侧键 2（前进）拖动。点击「确定」后，列表显示组合。要移除组合，在「鼠标按键」选择「无」后点击「确定」；点击「取消」则保留原配置。
4. 回到需要捕获的画面，先按住激活键，再用指定鼠标键拖动选择区域，松开后检查对应动作的结果。先用不重要的区域测试，确认动作与范围符合预期。

相同组合不能分配给两个动作；出现提示时改激活键或鼠标键。macOS 的全局鼠标需要对应系统权限；组合显示正确但没有响应时，检查应用权限和当前鼠标是否实际提供所选侧键。

## 全屏时自动停用与手动恢复

「全局快捷键」页的自动停用区域可以启用前台全屏窗口时停用，并选择适用的全屏窗口类型。游戏或全屏应用中快捷键不响应时，先离开全屏或检查该规则。

全局快捷键的启用/停用本身也有动作，可在主界面或托盘使用。托盘图标的停用标记与配置行的状态能帮助确认是否主动停用。不要在「暂时禁用」状态重复改键；先恢复启用，再检查真正的冲突。
