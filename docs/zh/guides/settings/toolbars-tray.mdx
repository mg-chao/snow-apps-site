# 工具栏、托盘与悬浮入口

工具可以被移动、叠放或隐藏。看不到某项功能时，先检查工具组和布局设置；隐藏按钮不等于卸载功能。

![拖到旁边创建位置，拖到上方叠放，拖入隐藏工具区隐藏](/images/guides/set-toolbars-tray.svg)

*操作示意。①并排，②叠放，③隐藏；叠放组底部工具显示在主行。*

## 找到相应工具栏编辑器

|要改的界面|设置入口|
|---|---|
|截图操作工具栏|设置 → 截图 → 操作工具栏|
|标注工具栏|设置 → 截图 → 标注工具栏|
|贴图操作工具栏|设置 → 固定到屏幕 → 操作工具栏|
|录屏操作工具栏|设置 → 屏幕录制 → 操作工具栏|
|桌面悬浮工具栏|设置 → 托盘与悬浮工具栏 → 悬浮工具栏|

## 重排、叠放、隐藏与恢复

1. 在对应设置分区找到工具栏预览。按住一个工具，拖到另一工具的**旁边**，出现插入位置后松开；它成为独立位置。
2. 将工具拖到另一工具的**上方**，松开后叠成一组。组内最底部工具留在主工具栏行，其余工具通过组展开选择。需要常用动作直接可见时，把它放到组底部或独立成列。
3. 把不常用工具拖进「隐藏工具」区域，预览中相应位置随之改变。要找回时，从隐藏区拖回预览。
4. 在真实截图、贴图或录屏窗口重新打开相应工具栏，悬停工具组检查展开后的项目，确认常用工具可达。

标注、贴图和录屏布局中的分隔线独立占据位置；录屏时长也独立占位。不要期待把它们当成普通动作叠入一组。想整体恢复时，使用该工具栏分区的重置，核对提示后再确认。

## 标注选择、工具记忆与颜色预设

打开「设置 → 截图 → 标注工具」，按自己的绘图习惯调整，再新建一个标注检查结果：

|设置|如何操作与检查|
|---|---|
|自动选中新创建的元素|开启后绘制一个对象，完成后它被选中，但当前绘图工具仍保持激活；适合每画一个就继续精调|
|禁止自动选中元素的工具|在多选列表指定例外；这些工具绘出的对象不随上述开关自动选中|
|禁止快速选择同类型元素的工具|勾选需要连续绘制的工具，避免工具激活时左键点到同类旧对象而进入选择；取消勾选则恢复同类对象的快速选择|
|删除光标后的文字|开启后，编辑文本时 Delete 删除选中文字或光标后的字符；先确认光标位于文本编辑中|
|记住上次使用的工具|开启后，新截图和贴图标注模式从上次标注工具开始；关闭则从移动工具开始|
|保持显示分组主按钮|开启后始终显示组的第一个按钮，而不是最近使用的工具；重新展开组核对入口|

同一分区的「描边颜色预设」「填充颜色预设」控制样式条上的快捷颜色。点击需要修改的预设色，选新颜色，再到具体标注工具查看快捷色；它不是批量重涂画布中所有对象。新对象样式与选中对象样式的区别见[标注基础](../annotations/basics)。

## 托盘图标与点击动作

打开「设置 → 托盘与悬浮工具栏 → 托盘」：

1. 开启托盘显示后，在系统托盘或 macOS 菜单栏找到图标。关闭后仍可通过主窗口和已配置快捷键操作。
2. 选择内置图标，或指定 **PNG/ICO** 自定义图标。可为深色主题单独设图标；在浅、深背景都检查轮廓。
3. Windows 可分别选择左键、中键动作，支持截图、复制、贴图、显示主窗口、历史、贴图管理、设置或无动作等。默认左键截图、中键贴图；macOS 不显示同样的中键配置。
4. 在托盘菜单选项中勾选希望出现的动作，打开实际菜单检查顺序与分组。全局快捷键开关、历史和窗口组等入口由配置决定。

macOS 的「让 macOS 控制托盘图标颜色」让菜单栏图标采用系统样式着色；它与自定义托盘菜单的背景皮肤不同。相关图片背景设置见[外观](./appearance)。

## 桌面悬浮工具栏

在悬浮工具栏分区开启「显示工具栏」，调整「工具栏不透明度」，再按上文编辑工具排列。该不透明度用于鼠标未悬停时；把指针移到图标或展开的工具栏上，会恢复完全不透明，移开后再检查所设效果。把常用截图、识别、贴图等动作放在容易点击的位置，避免不透明度过低而难以找到工具栏。

如果工具栏中某动作消失，先查看它是否在叠放组里，再到隐藏工具区恢复。若整条悬浮工具栏没出现，检查总开关。录屏工具栏的屏幕边缘自动隐藏是另一设置：到「设置 → 屏幕录制 → 操作方式」调整，并把指针移到边缘控制条恢复。
