# 存储、清理、配置备份与日志

应用数据、独立导出的图片/视频和配置备份用途不同。先看存储状态与占用来源，再决定迁移、清理或备份。

![查看数据占用后分别选择配置备份、历史清理或录屏临时文件清理](/images/guides/set-storage-backup.svg)

*操作示意。①查看占用与错误，②备份设置，③按数据类型清理。*

## 查看占用和存储位置

1. 打开「设置 → 导出与存储 → 数据存储」，查看数据目录、模式、总占用和最近错误。
2. 点击刷新，分别查看截图历史、贴图、OCR、录屏临时文件及其他占用。确认增长来自哪类数据后再清理。
3. 查看诊断、日志位置与日志状态。遇到故障时保留这里的信息，便于定位权限或写入问题。

模式可能显示应用数据、自定义目录、便携、只读（较新配置）或不可用。若提示配置来自较新版本，应使用兼容版本读取，避免手动修改数据库来绕过保护。

## Windows 修改数据目录

Windows 的数据存储区域提供目录选择。点击选择目录，指定可写位置，按对话框的迁移/使用方式完成；等待目录变更进度结束，再核对位置与占用。进行中不要同时运行清理或移动文件。

macOS 此处主要显示状态，不提供同样的 Windows 目录迁移按钮。只想换图片或视频输出位置，应改「图像导出」「视频导出」中的保存目录，而不是迁移全部应用数据。

## 导出和恢复配置

1. 在同一数据存储分区的「导出配置」项点击「导出」。在弹窗中选择是否包含「画布样式配置」，需要迁移保存的标注样式时勾选，再点击「导出」生成归档；点击「取消」则不导出。
2. 完成后提示配置已导出到剪贴板。到文件管理器粘贴并保存 ZIP 文件，取一个能识别日期或用途的名字；仅在剪贴板里还不算持久备份。
3. 恢复前先备份当前配置。在「导入配置」项点击「导入」，选择之前的 ZIP；在文件选择框取消则不导入。
4. 阅读替换确认：导入会以归档中的值替换当前应用设置，部分变化需要重启。点击「导入」确认替换；点击「取消」保留原配置。
5. 出现导入成功提示后检查主题、快捷键、保存目录等设置，并按需要重启应用。跨电脑迁移后，本地路径和设备条件可能不同，应重新核对。

配置归档用于应用设置，不等同于所有截图历史或视频的备份；重要输出文件仍应单独保存。日志归档也是另一种 ZIP，不要把它当作配置文件导入。

## 清理哪些内容

|入口|范围与操作前检查|
|---|---|
|截图历史的保留期限/条数/磁盘上限|影响历史保留；需要的图片先独立保存|
|清除截图历史|确认后清掉全部截图记录；不可用作临时筛选|
|贴图管理的保留限制|仅作用于已关闭窗口；保留窗口受到保护|
|清理已关闭记录|清除已关闭贴图记录，保留窗口不会因此被清除|
|删除临时录屏文件|删除已结束或中断录制遗留的工作文件；先完成需要的恢复|

每次清理都先阅读确认窗口；取消就返回。中断录屏还有待恢复源数据时，先去[录屏恢复与导出](../recording/trim-export)处理，再清理。历史保留策略详见[截图历史](../output/history)。

## 导出日志与排查保存失败

在「导出日志」点击「复制」，应用把日志和崩溃报告打包为 ZIP 放进剪贴板。到文件管理器粘贴归档，再交给需要分析的人。日志用于诊断，不是截图导出结果。

存储不可写时检查数据目录是否仍存在、磁盘空间与系统访问权限，恢复后刷新状态并做一次小的保存操作。「配置未能保存」时先解决数据存储，不要仅反复切换设置；尚未持久化的更改可能无法在重启后保留。
