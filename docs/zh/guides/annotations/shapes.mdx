# 矩形、椭圆与菱形

用图形框出按钮、段落或区域，比直接涂色更适合保留原文。**图形**工具提供矩形、椭圆与菱形，圆形和正方形通过等比绘制得到。

## 框出第一个区域

1. 完成截图选区，在主工具条点击 **图形**。
2. 在样式条选择 **矩形**。打开填充颜色，选透明；再选择一个与图像有反差的描边颜色和线宽。透明填充会保留框内的内容。
3. 在区域一角按住左键，拖到对角。画布显示形状预览；松开左键后，图形完成。
4. 切换 **选择元素**，点击图形边框。拖动图形本体可移位置，拖边缘或角落控制柄可改大小。
5. 点击空白处检查效果，再复制到剪贴板或保存为文件。

修改已有对象的专属样式时，先切回 **图形** 工具，再单击原有对象使其选中。**选择元素** 提供通用变形、层级与透明度操作；切换绘图工具会清除原选择，需要重新点选。

## 椭圆、菱形和等比绘制

在样式条切换 **椭圆** 或 **菱形**，再拖动创建。想把已有矩形改成椭圆，先切到图形工具并单击该图形，再切换形状，避免只改变新图形的默认样式。

- **Shift**：绘制时保持等比。矩形得到正方形，椭圆得到圆形；松开 Shift 后可继续调整长宽。
- **Alt（macOS 为 Option）**：绘制时以首次按下的位置为中心向外展开，适合围绕某个中心点标记。
- **Alt + Shift**：从中心等比绘制。先看预览，松开鼠标完成后再松开修饰键。

## 边框、内部与圆角

**描边颜色和宽度**决定边框。实线适合明确边界，虚线或点线适合提示范围；建筑师、艺术家、漫画家改变绘制外观。

**填充颜色**决定内部是否遮盖图片。只圈重点时用透明；做说明卡片时用实色。填充样式可选择实心、斜线或交叉线等纹理，先确认不会影响文字阅读。

**圆角**用于矩形。样式条可调整圆角数值；选中矩形时也可通过圆角控制柄修改。不同圆角允许分别设置，拖动时留意四角是否一起变化。椭圆和菱形的几何外观不按矩形圆角理解。

## 绘制后调整

切换 **选择元素**，选中图形后，用控制柄缩放或旋转。拖动图形本体只改变位置；拖动控制柄才改变几何形状。旋转后难以点中边框时，先放大画布再操作。

图形可以承载文字说明：选择文字工具在图形内部输入，完成后检查文字是否位于合适的范围。相关输入与排版见[文字](./text.mdx)。需要从图形连出关系线时，阅读[箭头](./arrows.mdx)。

## 画错或看不见图形

**图形挡住原文**：选中图形，把填充改为透明；只减小线宽不会去除内部遮挡。

**线框太淡**：检查描边颜色、线宽和对象不透明度，必要时改为实线。

**拖动变成新建图形**：拖动起点没有命中已有对象。几何编辑可先切换选择元素再点选；修改专属样式则回到图形工具，先单击边框选中再调整。

已完成的图形可用撤销回退，或选中后点击删除选中元素。最终输出和其他标注一起合成到图像，更多操作见[元素编辑](./elements.mdx)。
