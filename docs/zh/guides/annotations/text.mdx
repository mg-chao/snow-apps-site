# 文字标注与排版

文字标注用来补充说明、给对象命名或编写步骤。先准备好截图或打开图片，让可编辑画布和标注工具条显示。

## 输入并完成一段文字

1. 在主工具条点击 **文字**，在样式条选择文字颜色和字号。
2. 在需要放置说明的位置单击，出现文本输入区域。
3. 输入文字；需要多行时按 **Enter** 换行。输入过程中方向键和文本选择作用于文字内容；用 **Backspace** 删除前面的字符，Delete 的行为取决于下文的设置。
4. 输入完成后按 **Esc** 提交并结束输入，文字保留在画布上；也可按 Windows 的 **Ctrl + Enter** 或 macOS 的 **Command + Return**。先确认插入光标已消失，再切换工具。
5. 按 **V** 切换到 **选择元素**，点击真正的空白处清除选择，再从未选中的文字上一次按住左键拖到目标位置。不要先单击选中文字、再从字形处拖动；那会重新进入文字编辑。

## 重新修改内容

在 **选择元素** 或文字工具下，先点击已有文字使其选中，再点击文字内容进入编辑。看到插入光标后再输入；若仍只有外框，当前是对象选择状态。

修改完成后按 **Esc** 提交并结束输入。点击输入区域外也可完成输入；仍在文字工具中时，再点击空白会准备下一段文字。若出现不需要的空输入框，按 Esc 结束，再按 V 选择元素。

输入状态中，**Backspace** 删除所选文字或光标前的字符。**删除光标后的文字** 设置默认开启，此时 **Delete** 删除所选文字或光标后的字符；关闭该设置后，Delete 即使在输入中也会删除整个文字对象并结束输入。只想改字时先核对这一设置，或使用 Backspace。退出输入并选中整个对象后，Delete / Backspace 删除文字对象。

## 字体、字号与对齐

| 设置 | 用途 | 操作后检查 |
| --- | --- | --- |
| 字体 | 改变文字字形 | 某些字符是否由系统替代字体显示 |
| 字号 | 改变文字大小 | 是否遮挡原图，窄区域是否换行 |
| 粗体 / 斜体 | 强调词句 | 强调后是否仍易读 |
| 文字颜色 | 改变字本身 | 与背景的对比度 |
| 左对齐 / 居中 / 右对齐 | 安排多行或文字块 | 多行边缘和对象位置是否合适 |

修改文字专属样式时，先切到文字工具并单击目标，或进入该文本编辑。没有目标选择时，设置用于下一段文字。系统可用字体由当前机器决定；换设备后字体选择可能不同。

## 背景、边框与圆角

文字的 **填充颜色** 给说明加背景，适合放在复杂图片上；透明背景保留原图。填充样式可以改变内部纹理。**文字轮廓宽度与颜色** 用于描边，使字在背景上更清楚；与文字块背景分开调整。

文字块的背景、边框和圆角控件按当前文本样式提供。先输入较短说明，再调背景与边界；如果文字被遮挡，检查前景色、背景色以及上下层关系，不要只增加字号。

## 移动、缩放与旋转

移动文字时，先按 Esc 结束输入、按 V 选择元素，再点击空白处清除选择，直接从未选中的文字上按住拖动。若文字已经选中，拖动选框四周的留白或边缘，避开字形、四角缩放柄和旋转柄。

已选中后再次点击文字内容会进入输入，此时拖动是在选择字符。需要缩放或旋转时，结束输入后使用外框对应的控制柄。

在图形或箭头上添加文字时，画布支持与对象结合的文字布局。需要形状与说明一起移动时，创建后试着移动主体，确认文字随之变化；独立放置的文字仍可多选后一起移动。

## 修正与输出

内容输错时重新进入编辑；整段不需要时选中对象删除。插入光标仍在文字中时，Windows 的 **Ctrl+Z** 或 macOS 的 **Command+Z** 只撤销本次输入中的文字编辑，不会继续回退已完成对象。要回退对象移动、创建或删除，先按 **Esc** 结束输入，再点击工具条 **撤销**；用 **重做** 恢复。复制到剪贴板输出整张合成图，与在输入框中复制选中的字符不同。

**点击后出现新的空输入框**：没有点中已有文字。退出当前输入，切换选择元素，再按“选中 → 点击内容”进入编辑。

**拖动后只选中了字符，文字没有移动**：点击了已选中的文字内容，重新进入了输入。按 Esc 结束、按 V，点击空白清除选择后，从未选中的文字上直接按住拖动；缩放则拖角控制柄。
