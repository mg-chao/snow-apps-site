# 箭头

用箭头指出按钮、说明操作方向，或连接两个有关联的图形。Snow Shot 提供**直线箭头、曲线箭头、折线箭头**；同一支箭头的起点、终点符号可以分别设置。

先[截取一个区域](../capture/basics.mdx)，让截图工具条出现；也可以在[图像编辑](../image-editing/editor.mdx)中打开已有图片。以下操作都发生在可编辑画布上，复制或保存的是包含箭头的最终图像。

## 先完成一支箭头

1. 在截图工具条点击 **箭头**。悬停图标可查看名称；上方样式条切换为箭头选项。若工具被收进分组，先展开所在分组。
2. 在样式条选择 **直线箭头**。在颜色控件选一个与背景有反差的颜色，再选择合适的箭头宽度。
3. 将指针移到起点，按住鼠标左键，拖到要指出的位置。拖动时画布显示路径预览；在终点松开左键，箭头完成。
4. 如需修正，在主工具条切换 **选择元素**，点击刚画的箭头。选中后出现端点和控制柄，拖动端点改变起点或终点。
5. 点击空白处取消选中，检查箭头有没有挡住文字。点击 **复制到剪贴板**，再到目标应用粘贴；或点击 **保存为文件** 选择路径。

按住 **Shift** 绘制直线或曲线箭头时，当前线段方向按固定角度对齐，适合水平、垂直和斜向关系线。先拖动再观察预览是否符合要求；折线箭头有自己的正交路径，不套用同一角度约束。

## 三种路径怎么选

| 类型 | 适用场景 | 创建与调整 |
| --- | --- | --- |
| 直线箭头 | 指出一个位置、表达直接关系 | 从起点拖到终点；选中后拖两端或路径上的控制点 |
| 曲线箭头 | 绕开文字、让多条关系线容易区分 | 从起点拖到终点；选中后拖中间控制点改变弯曲程度 |
| 折线箭头 | 流程图、整齐的水平与垂直连线 | 拖动创建，或在起点、终点各单击一次；选中后拖折线段调整绕行位置 |

要改变已有箭头的类型，先点击 **箭头** 工具，再单击已有箭头，确认端点和控制柄出现后，在箭头样式条切换类型。**选择元素** 工具显示通用选择操作，不显示完整箭头样式；切换回箭头工具后需要重新点选对象。没有选中对象时，样式条设置用于之后新画的箭头。样式与选择的通用规则见[标注基础](./basics.mdx)。

### 连续点击绘制多点路径

直线、曲线箭头也可以逐点绘制：

1. 在起点**单击**，不要拖动。移动鼠标，预览会连接起点与指针。
2. 在下一处**单击**，固定这一点，再继续移动并单击添加后续点。
3. 在最后一个点**双击**结束，或者在已有点足够形成路径时按鼠标右键结束。
4. 若误入连续绘制，按 **Esc** 取消当前未完成路径，然后重新拖动创建。

## 起点、终点和箭杆

![十四种末端符号图标，包括箭头、竖线、圆形、三角、菱形和乌鸦脚](/images/guides/ann-arrow-endpoint-icons.svg)

*下图对照末端符号，起始端有对应方向的选择。<a href="/images/guides/ann-arrow-endpoint-icons.svg" target="_blank" rel="noreferrer">放大查看端点对照</a>。*

在箭头样式条中，分别打开 **起始箭头** 与 **末端箭头** 的图标选项。两端互相独立：只在终点选箭头可表达单向关系，两端都选箭头可表达双向关系；一端选“无”可去掉该端符号。

可选端点包括普通箭头、竖线、点、实心圆、空心圆、内凹三角、实心与空心三角、实心与空心菱形，以及三种乌鸦脚符号。以选项的图形和悬停提示为准，先看预览再确定是否适合表达当前关系。

**箭杆类型** 有 **普通箭杆** 和 **渐宽箭杆**。渐宽箭杆与普通、三角、空心三角、内凹三角箭头配合；其他端点需要先切回普通箭杆。若某个组合不可用，检查箭杆与端点是否匹配。

**箭头端点比例** 调整端点符号相对于箭杆的大小。在对应数值控件上滚动可调整，点击该控件恢复比例 1.0。箭头太大盖住目标时，先减小比例；整条箭杆也太粗时，再减小箭头宽度。

![相同线宽下普通和渐宽箭杆分别使用0.5倍、1倍和2倍端点比例](/images/guides/ann-arrow-shaft-ratio-engine.webp)

*比较普通、渐宽箭杆与0.5倍、1倍、2倍端点比例。<a href="/images/guides/ann-arrow-shaft-ratio-engine.webp" target="_blank" rel="noreferrer">放大查看箭杆与端点比例</a>。*

## 颜色、线型与轮廓

- **箭头颜色**：改变箭杆与端点的主体颜色；颜色弹出层同时提供线型与绘制风格选项。
- **箭头宽度**：改变主体粗细。细线适合密集界面，较粗的线适合演示中的重点指向。
- **实线、虚线、点线**：让关系类型不同的箭头易于区分；不要只靠颜色区分。
- **建筑师、艺术家、漫画家**：改变线条的视觉风格。需要整齐工程图时选建筑师，其他风格用于手绘感说明。
- **箭头轮廓宽度、箭头轮廓颜色**：在主体外增加轮廓，帮助箭头从复杂背景中分离。宽度为 0 时不绘制轮廓；浅色图片可用深色主体配浅色细轮廓。

修改现有箭头样式前，先切到箭头工具并单击目标箭头，观察样式条和对象是否同时变化。若只影响新箭头，通常是目标对象没有被选中。

![同样线宽下的实线、虚线、点线，以及无轮廓、细轮廓、粗轮廓箭头](/images/guides/ann-arrow-styles-engine.webp)

## 画完后继续编辑

切换 **选择元素** 后点击箭头，再进行操作：

| 想修改什么 | 在哪里操作 | 看见什么结果 |
| --- | --- | --- |
| 整体位置 | 拖动箭杆中部，避开控制点 | 整条箭头平移 |
| 指向位置 | 拖动起点或终点控制柄 | 该端点跟随指针，路径重新计算 |
| 曲线弧度 | 拖动中间路径控制点 | 曲线路径弯曲程度与方向变化 |
| 折线绕行 | 拖动折线的可编辑线段 | 该段位置改变，连接段保持正交 |
| 多点路径 | 拖动已有路径点 | 相邻线段随该点变化 |

靠近可连接图形边缘绘制或移动端点时，画布可能给出连接吸附反馈。按预览确认连接；连接后移动图形，箭头端点会随图形变化。若要精确指出图片上的像素位置，先远离图形边缘，避免误连。

箭头还可以带文字说明：用 **文字** 工具在箭头上创建文字，进入输入框后填写内容，按 **Esc** 提交并结束输入。已有文字可重新进入编辑。需要多行、背景或字体设置时参见[文字](./text.mdx)。

### 连线随图形移动，并带上说明

先让端点按预览吸附到图形，再用选择元素移动图形。需要说明时切换文字工具，在箭杆中部单击输入，按 Esc 提交并结束，再切换工具。

## 取消、撤销和输出

未完成路径按 **Esc** 取消；已完成但画错的箭头点击 **撤销**。用 **选择元素** 选中某支箭头后，可按 **Delete / Backspace** 或点击 **删除选中元素** 删除；想保留其他标注时不要重新截图。

所有箭头调整都应在导出前完成。复制到剪贴板、保存为文件得到的是图像；要继续调整箭头，请保留当前编辑窗口。若只是复制一支箭头的样式和位置，用选择工具条中的 **复制选中元素**，它在画布中生成副本，与复制最终截图不同。

## 常见问题

**点击后一直有一段线跟着鼠标。** 这是逐点绘制状态。继续添加路径点，最后双击结束；不需要这条路径时按 Esc，再用按住拖动的方式创建。

**切成折线后，不能用点击增加拐点。** 折线箭头由起点、终点和正交路由组成。完成后选择箭头，通过可编辑线段改变绕行，不使用多点箭头的创建方式。

**端点符号不能与当前箭杆组合。** 渐宽箭杆支持的端点有限。先切为普通箭杆，再选所需符号。

**曲线编辑时变成整体移动。** 先确认箭头被选中，再拖控制点；拖线条本体会移动对象。放大画布可更容易分辨端点和中间点。
