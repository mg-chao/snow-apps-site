# 括号标注

括号标注把多行文字、多个按钮或一组图形归为一类。它适合表达“这些内容属于同一组”，可配合独立文字写组名。

## 拖出一个括号

1. 在截图工具条点击 **括号标注**，设置颜色和线宽。
2. 在分组范围一侧按住左键，向对角方向拖动，同时拉出高度与宽度。
3. 观察预览中的上下跨度和中间指引，松开左键完成。纯水平或纯垂直、没有有效宽高的拖动可能无法生成括号。
4. 切换选择元素，点击括号，拖控制点把上下端对齐到分组范围。
5. 在旁边用文字工具写出组名，取消选中检查后复制或保存。

修改已有对象的专属样式时，先切回 **括号标注** 工具，再单击原有对象使其选中。**选择元素** 提供通用变形、层级与透明度操作；切换绘图工具会清除原选择，需要重新点选。

## 跨度与朝向

拖动端点控制柄调整括号覆盖的范围；拖动括号的中间指引控制点调整括号展开的方向与深度。先把上下端放到分组边缘，再把中间指引移到合适位置，避免一次大幅拖动难以判断变化。

拖括号本体会移动整个对象。若只想改其中一端，确认指针落在对应控制柄上；框选多个元素后操作会影响整组选择。

## 样式与配合文字

颜色和宽度在括号样式条设置。较细括号适合正文旁边，较粗括号适合演示大图；应该与文字或形状的线宽保持协调。

括号说明使用文字工具单独输入。移动分组时可以把括号和文字一起多选，再整体移动；不应假设独立文字会自动绑定到括号。

## 没出现或位置不对

**松开后没有括号**：重新拖动，确保同时有横向和纵向距离，且拖动范围足够形成预览。

**拖动后整个括号都移动了**：当前拖的是线条本体。撤销，重新选择控制点。

绘制途中可按 Esc 或右键取消；完成后点击撤销，或选中对象删除。相关教程：[距离标注](./distance.mdx) · [角度标注](./angle.mdx) · [文字](./text.mdx)。
