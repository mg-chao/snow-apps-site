# 矩形高亮与画笔高亮

高亮适合在保留原文的同时突出重点。Snow Shot 提供 **矩形高亮** 与 **画笔高亮**：前者覆盖一块区域，后者沿起点与终点形成高亮线段。

## 高亮一段文字

1. 在截图工具条打开 **高亮**，选择 **矩形高亮**。
2. 在样式条选择高亮颜色。先选与文字反差适中的颜色，避免过深遮住内容。
3. 在段落左上角按住左键，拖到右下角，预览覆盖需要强调的区域；松开后完成。
4. 切换 **选择元素**，选中高亮后调整位置或范围，确保首尾字都在区域内。
5. 取消选中，检查文字可读性，再复制或保存。

修改已有对象的专属样式时，先切回 **矩形高亮或画笔高亮** 工具，再单击原有对象使其选中。**选择元素** 提供通用变形、层级与透明度操作；切换绘图工具会清除原选择，需要重新点选。

## 用画笔高亮标一行

1. 选择 **画笔高亮**，先设置高亮颜色和笔画宽度。
2. 在一行文字左侧按住左键，拖到右侧，松开后形成一段高亮。
3. 按住 **Shift** 拖动时，线段方向按 15° 增量对齐，便于画水平的高亮带。

画笔高亮按起终点形成线段，不能按自由画笔的方式期待任意弯曲轨迹。要强调曲折轮廓，使用画笔或多段高亮分别完成。

## 调整样式与范围

矩形高亮可以设置高亮颜色、轮廓颜色与轮廓宽度；边框用于区分紧挨着的几块重点，宽度为 0 时不增加轮廓。画笔高亮通过宽度决定覆盖高度，太宽会影响相邻行，太细会漏掉字的上下部分。

修改已有高亮样式时，先回到对应高亮工具，再单击原有高亮使其选中。矩形通过边角控制柄改变范围；线段式高亮通过两端位置改变长度和方向。想统一多个高亮的透明度，可多选后使用选择工具条的不透明度。

## 避免重复覆盖

多次高亮同一处可能让显示效果变深。先用选择元素检查有没有重叠对象，删除多余的一层，再调颜色。看不清原文时，先减小不透明度或换较浅颜色，再检查有没有实色形状挡在上面。

画错后点击撤销，删除单个对象用选择元素或元素橡皮擦。需要只照亮一块、同时压暗其他内容，使用[聚光灯](./spotlight.mdx)。
