# 电脑怎么截长图：Windows 与 macOS 滚动截图教程

在 Windows 或 macOS 使用 Snow Shot，可以把网页、聊天记录和宽表格截成一张长图：框选滚动内容，手动或自动滚动，检查拼接预览，再裁剪首尾并复制或保存。滚动截图通过连续画面的重叠部分进行拼接；开始前先让页面加载稳定，回到需要的起点，并关闭遮挡内容的弹层。

## 选择内容区并开始

1. 使用截图快捷键（Windows 默认 **F1**，macOS 默认 **Control+1**），只框选会随滚动变化的内容。尽量排除固定页头、聊天输入框、侧栏和滚动条。
2. 点击截图工具栏 **滚动截图**，默认局部快捷键 **L**。区域切入滚动捕获，旁边出现拼接预览和滚动操作控件。
3. 选择 **垂直滚动** 或 **水平滚动**。先用一小段手动滚动确认目标面板正确；改变方向会清空已有拼接结果及首尾裁剪范围，再按新方向重新采集；需要旧结果时先保存，因此开始连续捕获前先确定方向。
4. 把指针放在内容区，平缓滚动，让前后画面保持重叠。预览应随新内容增长，重复回到已有内容不应被当成新的整页无条件追加。

## 手动、自动与横向滚动

手动模式由你控制目标应用的滚轮或滚动条。横向内容要使用能使目标面板水平移动的输入；如果滚动发生在错误面板，先暂停操作，把指针放回正确区域，再试一小步。

点击 **自动滚动** 开关，应用按所选方向发送滚动输入。再次点击可停止自动输入；此时保留已拼接结果，可以检查后继续。旁边的 **自动滚动间隔** 控件支持 **128–1000 ms**：较大间隔给应用更多时间更新，较小间隔更密集；单击该数值恢复 **200 ms**。先用默认值测试，目标内容更新较慢时增加间隔。

自动滚动不等于目标应用一定接受了滚动。预览没有增加时，先检查目标面板能否手动滚动、是否已经到底、输入是否被浮层拦截。不要只根据自动开关处于开启状态判断长图已经完整。

## 看清拼接结果，修正开头与结尾

先关闭 **自动滚动**，再把鼠标移到缩略预览中的某一段。对应的拼接细节会临时显示在原捕获选区内；指针移出缩略图后，原目标页面重新可见。自动滚动开启时，普通悬停不会进入这项细节预览。较长预览出现滚动条时，在预览内滚动可浏览已拼接范围；这与在原内容区滚动并捕获新内容不同。

需要去掉开头或结尾时，先停止自动滚动，将指针移到预览的首尾裁剪边界，看到调整方向指针后按住左键拖动。垂直长图调整顶部/底部，水平长图调整左侧/右侧；拖动中会显示边界附近内容，松开后保留裁剪范围。需要恢复更多内容时，在结果仍保留的状态把边界向外拖回，而不是马上重新截图。

选区只能沿当前滚动方向移动：水平滚动时，按住 **水平移动选区（按住并拖动）** 向左或右拖动；垂直滚动时，按住 **垂直移动选区（按住并拖动）** 向上或下拖动。另一方向的控件不可用。松开结束移动，选区宽高不变。先停止自动滚动再调整，避免一边移动一边误判拼接变化；需要大幅改变范围时，重新准备内容并开始新一轮更容易检查。

## 完成并取得长图

停止自动滚动，浏览整个预览，确认没有缺行、重复或动态内容遮挡，再选择结果去向：

| 操作 | 得到的结果 |
| --- | --- |
| **复制到剪贴板** | 拼接、裁剪后的长图，可到其他应用粘贴 |
| **保存为文件** | 选择位置与格式保存，打开文件检查完整尺寸 |
| **固定到屏幕** | 将长图作为桌面贴图继续查看 |
| **图像编辑** | 把拼接结果交给编辑窗口继续标注、处理 |
| **图像切分** | 按需要把长图切成多段，便于分享或排版 |
| 关闭 / Esc | 放弃当前截图工作流 |

编辑和切分见[图片编辑](../image-editing/editor.mdx)与[图片分割](../image-editing/split.mdx)。

需要排除 Snow Shot 自己的工具条或缩略预览时，在滚动工具条上悬停辨认 **设置**，打开 **滚动截图设置**，关闭 **滚动截图时捕获界面**。这不是排除网页或目标应用的固定页头，固定内容仍须在框选时避开。

**更改开关并点击确定后，会清空已有拼接结果和首尾裁剪范围，重新开始采集；捕获选区和滚动方向保持不变。** 需要保留当前长图时先保存，再重新开始截图。点击 **取消** 不更改设置；没有更改开关便直接确定，不会重新采集。若出现无法保存设置的提示，先保留当前结果，再重新打开设置尝试。

![先保存当前拼接结果、更改滚动设置、清空旧裁剪并重新采集的流程](/images/guides/cap-scrolling-settings-reset.svg)

*操作示意：设置更改后的新采集不会接着使用旧拼接结果。*

## 拼接不正确时

| 现象 | 原因与处理 |
| --- | --- |
| 页头/输入框重复 | 选区含固定内容，重新框选只滚动的正文 |
| 丢行或错位 | 前后画面重叠不足，放慢滚动或增大自动间隔 |
| 同一行字反复出现 | 内容变化、动画或重复纹理影响匹配，用较短片段对照 |
| 没有新增内容 | 检查滚动目标、是否到底、页面是否响应输入 |
| 图片加载后位置跳变 | 先让图片和异步内容加载完整，再回到起点重试 |
| 预览很长却不易确认 | 在预览内逐段浏览，特别检查接缝，再考虑切分 |

滚动过程中保持窗口尺寸、页面缩放和显示器配置稳定。虚拟列表会替换可见内容，动态视频会持续改变像素；持续不稳定时分段截图，不把未检查的预览当成完整记录。
