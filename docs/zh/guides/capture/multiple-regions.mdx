# 多区域截图与区域组合

只需要窗口中的几块信息，或想去掉选区中的一块内容时，可以在同一次截图中组合区域。每个区域仍来自当前捕获的画面；不同时间或不同文件的拼接使用[拼图](../image-editing/collage.mdx)。

## 添加第二个区域

1. 使用截图快捷键（Windows 默认 F1，macOS 默认 Control+1） 框选第一块内容，切到 **移动**。样式条出现区域增加、减少和形状选择等控件。
2. 点击 **添加截图区域**，选择矩形或需要的区域类型。按住左键框出第二块内容，松开后第二块区域加入当前选区。
3. 检查两块区域都保留。指针在某个保留区域内部拖动，可调整该块区域的位置；移动整组选区时按住默认 **Space**，拖动完成后松开。
4. 继续添加其他区域，或切回移动状态准备整理。开始添加后若不想继续，按 **Esc** 先取消当前区域操作，已有区域仍可继续处理。

## 减去不需要的部分

点击 **减去截图区域**，在当前选区内绘制要排除的范围。完成后，被减去的部分不再属于保留区域。矩形、折线、曲线和自由绘制使用各自的结束方式，见[不规则区域](./irregular-regions.mdx)。

减去范围不与现有区域相交时，输出不会发生你期望的变化。需要恢复时，先取消未完成的区域操作；已经提交的修改，重新框选或添加所需内容。这里是截取区域的组合操作，不会自动识别或替换被排除处的背景。

## 移动与快速复制区域

多区域状态下，移动工具识别具体保留区域；两块之间的空隙不会自动变成可拖动区域。要移动某块，把指针放在这块内；要移动整组，按住“移动整个选区”的绑定键（默认 Space）再拖动，松开键后返回单块移动。按住 **Windows Ctrl / macOS Command** 移动单块可启用区域吸附，观察边缘对齐反馈后松开。

把鼠标放到需要放置副本的位置，按默认 **R**，会复制**最后创建的区域范围**，把新范围的中心放到指针附近，并在屏幕边界内约束位置。该动作只在多区域、移动工具且没有正在绘制/拖动时生效。同一个 R 在普通单选区有复用上次选区的上下文，不要在不同状态下期待相同结果。

## 紧凑布局、间距与背景

**紧凑布局** 将多区域的内容靠拢，减少原来位置之间的空白。打开后在 **布局间距** 控件上滚动调整，单击该控件恢复为 0。此控件只适用于多区域，普通单区域显示不可用时无需排查安装问题。

**选区背景不透明度** 控制区域之外、合成边界之内的背景参与程度。在数值控件上滚动调整，单击恢复 **0%**。需要透明背景时，保存为支持透明度的格式并在查看器中检查；目标聊天或文档应用也可能把透明部分显示为自己的背景色。

## 输出前的检查

在 **复制到剪贴板**、**保存为文件** 前，检查每块区域的文字有没有截断、区域间距是否合适以及排除内容是否确实消失。导出会形成一张合成图片，不能靠普通图片文件恢复独立区域的编辑状态。

需要更复杂的排列、翻转或多张来源图片，转到[拼图教程](../image-editing/collage.mdx)；需要给某一块增加箭头或说明，先完成范围整理，再使用[标注工具](../annotations/basics.mdx)。
