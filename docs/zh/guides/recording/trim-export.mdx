# 预览、裁剪、变速与导出

录屏包含开头等待或结尾收尾时，用裁剪保留有效区间；操作节奏太慢时，用速度选项调整播放和导出速度。需要声音时在录制前选择 MP4。

## 进入预览并裁掉头尾

1. 在录制中或暂停状态，点击录屏工具栏的「裁剪视频」。应用会结束采集并准备预览；等待时间轴可用后再拖动。
2. 时间轴左端是「裁剪起点」。向右拖动左端控制柄，观察预览画面跳到新的起始帧，停在希望保留的第一帧。
3. 右端是「裁剪终点」。向左拖动右端控制柄，观察预览切换到保留区间末尾，停在希望结束的位置。两端不能越过彼此，至少保留一帧。
4. 点击「重播」，从保留区间起点检查；「播放/暂停」只控制当前预览。拖动时间轴定位后，可以检查具体帧。
5. 不满意时重新拖动起点或终点，直到开头、结尾和中间操作连贯。

## 改变播放与导出速度

时间轴旁的「速度」提供 **0.25x、0.5x、0.75x、1.0x、1.25x、1.5x、1.75x、2.0x、3.0x**。选择后同时影响预览和导出的速度，不能把它当作仅用于预览的播放器速度。

选择 1.5x 后，先重播确认文字和操作仍可看清；需要恢复原节奏时选回 1.0x。裁剪区间和速度是不同设置，改变速度不会替你去掉头尾等待。

## 保存与复制结果

裁剪预览中，点击「保存到文件」，选择目标文件路径；不要用原始录制文件路径覆盖原始文件，应用会提示选择其他文件以保留原始录制。点击「复制录制内容」时，结果以文件形式放入剪贴板，可粘贴到接受文件的应用。

等待渲染完成后再播放、发送或移动结果。进度窗口区分准备、渲染和完成处理阶段；取消渲染后，可选择「重试」或「保留源文件」。出错时提示中会显示源文件目录，保留该目录后再处理恢复问题；「丢弃」用于确认不再需要源数据时退出。

## 录制前选择输出参数

「设置 → 屏幕录制」以及录屏界面的「屏幕录制设置」共用普通录屏参数。格式、效果和摄像头在「导出设置」中配置。

|参数|如何选择与观察结果|
|---|---|
|屏幕录制清晰度|4K、2K、1080p、720p、480p 为最大输出尺寸限制；超过上限时缩小，不会凭空补回细节|
|帧率|5、10、15、24、30、60、120、83；连续运动需要更高帧率，静态操作可降低以减少数据量；高设置仍受采集能力影响|
|视频画质|调整 MP4 画质和体积；先以短片比较文字边缘和文件大小|
|编码器|H.264、H.265 及各自硬件选项；H.265 需接收方播放器支持，硬件不可用时回退同编码的软件实现|
|编码预设|从极速、非常快、中等、非常慢到极致压缩，平衡处理速度与压缩效率|
|动图清晰度|1080p、720p、480p，独立于视频参数|
|动图帧率|5、10、15、24；提高前先考虑文件体积|
|循环播放动图|控制保存后的 GIF、APNG、WebP 是否循环播放|

默认视频配置为 1080p、30 帧、H.264、质量 80；动图默认 720p、10 帧。已有配置以界面显示为准。文件保存位置与命名格式在「设置 → 导出与存储 → 视频导出」调整。

## 预览或导出异常

预览不可用时，先记录具体错误并保留源文件；不要通过反复点击导出来覆盖问题。导出目录不存在或不可写时改用可写目录。文件很大时降低动图尺寸或帧率；文件无法播放时核对扩展名、编码器和播放器支持，并先用 H.264 MP4 做短片检查。
