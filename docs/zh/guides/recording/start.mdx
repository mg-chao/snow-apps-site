# 录屏区域与开始暂停停止

录屏适合演示连续操作。先确定画面范围和输出格式，再开始采集；需要整理桌面时用暂停，完成后用停止取得文件。

## 进入并确定范围

1. 在主窗口的「全局快捷键」页找到「屏幕录制」并执行，或先启动截图、框选内容，再点击操作工具栏中的「屏幕录制」。出现录制边框和录屏工具栏后，才进入录屏准备状态。
2. 开始前，将指针移到录制边框或拖动位置，拖动调整位置和大小。观察边框，确认待演示的窗口、弹出菜单都在区域内；工具栏会随区域重新放置。
3. 打开录屏工具栏的「导出设置」，在「录制格式」中选 MP4、GIF、APNG 或 WebP。需要声音选 MP4；后三种是无音频动图。
4. 如需准备时间，在「延迟录制（滚动调整）」控件上滚动调整秒数；点击该控件恢复为 0 秒。随后点击「开始录制」，有延迟时先显示倒计时，等待结束后再操作。

录制已经开始、暂停或正在处理时，不能像准备状态一样修改采集区域。需要不同范围时先结束本次录制，再重新选择。

## 按状态控制录制

|当前状态|在哪里操作|操作后看什么|
|---|---|---|
|准备中|「开始录制」|启动或倒计时期间按钮显示忙碌，启动完成后可暂停和停止|
|录制中|「暂停录制」|进入暂停状态，出现「继续录制」；整理窗口时不用录下等待过程|
|已暂停|「继续录制」|回到录制状态，继续采集后续操作|
|录制中或已暂停|「停止录制」|结束采集并处理输出；等待结束再使用文件|
|录制中或已暂停|「复制录制内容」|结束采集并把录制文件放到剪贴板，可在接受文件的应用粘贴|

开始、暂停和继续共用一个可配置的录屏快捷键动作；它根据状态执行不同操作。实际按键在「设置 → 应用快捷键 → 屏幕录制」查看，工具提示也会显示当前绑定。不要在启动或停止的忙碌阶段反复点击。

「关闭录制」用于离开录屏窗口，与停止保存不同。在「设置 → 屏幕录制 → 操作方式」开启「关闭录制时删除文件」后，关闭活动录制会删除本次文件；需要结果时优先使用停止或复制。

## 控制工具栏与提示

在「设置 → 屏幕录制」可以调整以下行为：

- **录制时捕获工具栏**：决定录屏工具栏是否进入画面。想让观众看到控制过程时开启；不想录下工具栏时关闭。
- **自动隐藏工具栏**：将工具栏靠近屏幕左、右边缘，离开后收起；把指针移到边缘控制条上可重新显示。
- **显示录制状态提示**：在动效预览区域中央显示格式、麦克风和系统音频状态，开始前用它核对声音设置。
- **录制结束后自动退出**：保存后自动离开录屏界面。
- **导出完成后通知**：完成后显示系统通知，点击通知定位输出文件。

输出目录与文件名位于「设置 → 导出与存储 → 视频导出」。默认位置是系统视频目录，改过设置后以该字段为准。需要裁掉头尾，先进入[裁剪预览](./trim-export)，再导出。

## 无法开始或找不到结果

macOS 首先检查「设置 → 应用权限」中的屏幕与系统音频录制权限；需要声音、摄像头或按键展示时，还要准备对应设备与权限。Windows 的「设置 → 屏幕录制 → 录制内容」有录制 API 选项；遇到黑屏或不兼容画面时可切换后重新开始短录制，不能假定不同 API 都能捕获受保护内容。

如果提示无法创建录制目录，到「视频导出」重新选择可写目录。渲染出错时保留提示中的源文件夹，在失败窗口选择「重试」；不需要立即恢复时选择「保留源文件」。不要先清理临时录屏文件。Windows 在系统会话中断后可能出现恢复提示，可选择「恢复」或「打开文件夹」。
