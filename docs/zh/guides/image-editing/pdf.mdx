# 图片转 PDF 与纸张排版

PDF 输出把多张图片排到纸张上，适合证件正反面、扫描资料和要打印的截图。Snow Shot 从 **图像拼接** 输出 PDF；这项功能不用于编辑任意已有 PDF 的文字。

## 从图片进入 PDF 模式

1. 从主窗口的 **拼接选中的图像** 动作打开 **图像拼接**，点击 **添加图像** 或拖入素材，等待加载完成。
2. 在设置区把 **图像类型** 从静态图像切换为 **PDF 文档**。预览与设置随之切换为纸张排版。
3. 选择 **拼接方式**：分页拼接或模板拼接。
4. 设置纸张大小、方向和页边距，检查预览页数以及每张图的位置。
5. 选择导出模式，点击保存，按提示选择 PDF 路径或目标目录，等待导出完成。

## 分页拼接与模板拼接

**分页拼接**适合每张素材分别占据页面的资料，按图像顺序安排页。检查页缩略图，必要时调整素材次序。

**模板拼接**把多张图放在一页的格子中，可选择两图、三图至九图，以及 **身份证** 模板。模板决定格子布局；每张素材仍需要检查方向与可见范围。

证件正反面先确认素材顺序，再选身份证模板。图片有边缘空白时，在格子内调整位置与缩放，让有效区域合适地落在纸张上。

![分页输出将卡片正反面各放一页，身份证模板在同一张纸上安排两个卡片区域的对比](/images/guides/img-audit-pdf-layout.svg)

*操作示意。卡片保持特定长宽比并受纸张与格子范围限制，不表示打印一定为证件实物尺寸。*

## 纸张、方向与边距

纸张选项包括 A3、A4、A5、B5、Letter、Legal、自定义，以及适用模式下的图像尺寸。**自定义纸张**输入宽和高；**纵向 / 横向**改变纸张朝向；**页边距**决定纸张边缘的留白。

尺寸与边距使用毫米。边距过大可能没有足够放置区域，出现字段错误时先修正参数，再检查预览。使用图像尺寸时，页面按图像尺寸生成，不按普通纸张边距和方向理解。

模板模式还可设置 **图片间距**。不要把图片间距当成页边距，前者分隔格子中的图片，后者隔开内容与纸边。

## 调整页内图片

选中预览中的图片，可移动、缩放，并使用顺时针 / 逆时针 90°、水平 / 垂直翻转和重置变换。放大图片后，超出当前格子的部分会被裁切；先确认文字和证件边缘没有被截掉。

旋转用于修正横竖方向，翻转会镜像文字，文档图片通常应避免误用。每次变换后检查下一页或其他格子，确保没有因为排序或选择错误改到另一张图。

## 合并或逐页导出

- **合并导出**：把所有页面写入同一个 PDF，适合连续资料。
- **逐页导出**：每页单独写为 PDF，按提示选择目标目录，适合分发独立页面。

导出中会显示页数和进度。需要停止时点击取消，等待“正在取消导出”结束；核对结果中的已保存文件和未保存页，不要把已有的部分文件当作完整文档。

导出失败时保留排版窗口，检查目标目录、磁盘空间和错误提示，再重试；部分成功先确认已有文件。完成后打开 PDF 检查页序、纸张方向、边缘与细字。
