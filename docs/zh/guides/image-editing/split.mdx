# 图片分割与手动切线

图片分割把一张长图或大图切成多张独立图片。智能分割先寻找适合的分界位置，等分和精确分割则按数量或尺寸生成切线；所有结果都应先检查再导出。

## 导入并建立分割

1. 在主窗口的 **搜索功能** 搜索 **分割选中的图像**，选择结果后单击动作行，打开 **图像分割**。点击 **选择图像**，或拖入一张图片文件；每个窗口只处理一张图。
2. 等待图像显示，选择 **分割方向**：纵向、横向或网格。
3. 在 **分割类型** 选择智能分割、均等分割或精确分割。智能分割会显示正在寻找分割线的状态，完成后出现预览线。
4. 查看图片总数与各条切线的位置，放大检查切线有没有穿过正文或关键对象。
5. 调整切线后点击 **保存全部**，选择目标文件夹，等待逐张保存完成。

## 从文件管理器的所选图片开始

在主界面的 **全局快捷键** 中找到 **分割选中的图像** 并设置一个没有冲突的全局快捷键；该动作没有预设按键，不能直接套用截图快捷键。然后回到系统文件管理器，选中一张或多张图片文件，按刚设置的快捷键，每张图片分别进入独立图像分割窗口。

没有选中图片时，动作打开空窗口，可以继续用窗口中的选图入口添加素材。macOS 如果提示 Snow Shot 请求控制 Finder 来读取所选文件，按系统提示授予相应自动化权限后重试。快捷键的配置与冲突处理见[快捷键设置](../settings/shortcuts.mdx)。

## 按数量、尺寸或内容分割

| 类型 | 输入或依据 | 适合 |
| --- | --- | --- |
| 智能分割 | 图像内容与空白分界 | 长文章、聊天截图等，需人工复核 |
| 均等分割 | 图片数量，或网格行数与列数 | 需要相近大小的切片 |
| 精确分割 | 每张宽度或高度，支持像素或百分比 | 需要规定尺寸或页面长度 |

纵向切长图时主要关注每张高度，横向关注宽度，网格同时关注行列。界面出现正整数、至少 16 像素等校验提示时，按字段提示修正，确认预览重新有效。

## 用标尺修正切线

1. 在预览的标尺上点击目标位置，添加一条切线，画面出现对应分界。
2. 拖动已有切线，观察位置坐标，避开文字或图形中心。
3. 点击切线使其选中，按 **Delete** 删除不需要的线。
4. 中键拖动平移预览，滚轮放大或缩小；看不清整体时点击 **适应画布**。

智能分割没有找到理想位置时，保留已合理的切线，再补加或移动。不要因为是自动结果就跳过人工检查。

## 重叠宽度与撤销

**重叠宽度**让相邻切片在分界线外额外保留同一段像素，适合需要前后文衔接的长图。设为 0 时不额外保留重叠；增大后检查是否产生过多重复内容。

编辑切线后用 **撤销 / 重做** 修正。点击 **重新加载** 会打开选择图片入口，用来重新选择或更换来源；操作前确认是否需要保留手动改线。替换图片会提示当前分割编辑将被丢弃，核对后再确认。

## 保存与转 PDF

点击保存全部后，应用显示“正在保存图片：已完成数 / 总数”。完成提示包含保存数量与目录；如果只保存了部分切片，核对失败信息和已保存文件，再重试，避免把部分成功当成完整结果。

需要纸张文档时点击 **拼接为 PDF**，分割结果会交给 PDF 排版流程。在新的预览中检查页序与纸张，再导出，参见[图片转 PDF](./pdf.mdx)。若提示图像拼接正忙，等待当前拼接任务结束后重试。
