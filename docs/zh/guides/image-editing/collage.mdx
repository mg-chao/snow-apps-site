# 图片拼接与排版

图片拼接把多张独立图片排成一张，适合教程步骤、对比图和资料汇总。连续滚动的网页或聊天记录应优先用[滚动长截图](../capture/scrolling.mdx)，拼接则用于已有图片的排版。

## 组合第一组图片

1. 在主窗口的 **搜索功能** 中搜索 **拼接选中的图像**，选择结果定位后单击动作行，打开 **图像拼接**。
2. 点击 **添加图像**，可一次选择多张文件；也可把多张图片拖入窗口。等待加载进度完成。
3. 在 **图像类型** 选择 **静态图像**，预览显示当前图片组合。
4. 在 **布局方向** 选择 **垂直** 或 **水平**。查看输出宽高和图片总数，确认所有图片都已加入。
5. 调整顺序与间距，最后点击窗口底部的 **复制** 或 **保存**。复制成功后窗口关闭，到目标应用粘贴检查；保存会打开保存选项，选择需要的格式和路径，完成后到文件管理器检查结果。取消保存选项会回到当前拼接，图片仍保留。

### 从剪贴板追加图片

要从剪贴板追加图片，可先在图像查看器中复制图像内容，再返回拼接窗口。结束数值或文字输入，单击预览使它获得焦点，按 **Ctrl+V（macOS 为 Command+V）**，等待新增图片出现在缩略图中；加载或导出时先等待。粘贴是追加，已有图片及其旋转、翻转和位置保留，不会替换当前选中的图。

剪贴板提供可读取的本地图片文件列表时，会按列表顺序追加，重复文件也会保留；部分文件无法读取时，核对错误列表及已加入的图片。**PDF 文档**模式同样可以追加，已有图片的变换保持，再检查页序与格子。

粘贴后先核对新增图片的内容与尺寸。若看到的是文件图标，改用 **添加图像** 或拖入文件，或在图像查看器打开原图、复制图像内容后再粘贴。

## 从文件管理器的所选图片开始

在主界面的 **全局快捷键** 中找到 **拼接选中的图像** 并设置一个没有冲突的全局快捷键；该动作没有预设按键，不能直接套用截图快捷键。然后回到系统文件管理器，选中多张图片文件，按刚设置的快捷键，所有图片加入同一个图像拼接窗口。

没有选中图片时，动作打开空窗口，可以继续用窗口中的选图入口添加素材。macOS 如果提示 Snow Shot 请求控制 Finder 来读取所选文件，按系统提示授予相应自动化权限后重试。快捷键的配置与冲突处理见[快捷键设置](../settings/shortcuts.mdx)。

## 纵向、横向和自定义网格

**垂直**适合步骤长图，图片从上到下排列；**水平**适合前后对比；**自定义**显示行数、列数设置，适合多图网格。行数和列数都需为正整数；格子放不下所有图片时，列数会增加，删除图片后也不会自动缩掉已有空格子。调整后核对新的行列值和留白。

修改行列后检查每张图是否完整落在预期格子中。**统一尺寸**让排列更规整；**原始尺寸**按原有尺寸组织内容。当素材长宽比不同，先选择更适合的方向，再决定是否需要在格子中局部裁切。

![同一组图片分别按纵向、横向和自定义网格排布的教学示意](/images/guides/img-audit-layout.svg)

*操作示意。相同素材只改变排列方向，先检查顺序与空格子。*

在自动纵向布局中，**统一尺寸**把每张图片等比缩放到第一张图片变换后的宽度；自动横向布局则以第一张图片的高度为参考。**原始尺寸**保留各图尺寸，较窄或较矮的图片在交叉方向居中。先固定顺序和方向，再切换策略比较，避免把排列改变与尺寸改变混为一谈。

自定义网格的 **统一尺寸**以第一张图变换后的宽高作为格子大小，其他图等比适应并居中；**原始尺寸**以全部图片中的最大宽、最大高决定格子，保留各图自身尺寸并居中。空白并不一定是缺图，也可能来自长宽比差异。

![不同尺寸来源在相同纵向排列中，统一宽度与保留原始尺寸的对比](/images/guides/img-audit-size.svg)

*操作示意。B、C 的宽度变化由首图参考尺寸决定，图片长宽比保留。*

## 边框、间距和背景

**外边框**是整张组合图外围留白，**图像间距**是相邻图片之间的空隙。两者都输入不小于 0 的值，可用像素或百分比单位。百分比的参照随布局变化：垂直布局以调整尺寸后的最宽图片为准，水平布局以最高图片为准，自定义布局以格子宽度为准。例如参照宽度为 1000 px 时，10% 对应 100 px。切换单位会换算显示值；再修改数值后，观察预览和输出尺寸。

**背景颜色**决定留白与未覆盖部分，可选透明色。需要透明输出时保存为支持透明的图像格式，并检查导出结果，普通不透明格式不能保留相同的透明背景。

## 排序与单图变换

点击下方缩略图定位对应图片。拖动缩略图到另一张上方并松开，可以交换顺序；点击 **反转图像顺序** 把当前图片顺序反转。交换会重置这两项的格内位置与缩放，反转会重置实际换位项的位置与缩放；旋转和翻转保留，重排后重新检查裁切。

在预览中单击一张图，旁边出现该图的操作条。悬停图标核对名称，再按需要操作：

- **移动或交换**：拖图片改变格内位置，或拖向另一张图交换位置。
- **缩放**：拖选中控制柄，图片围绕中心缩放；放大后格子边界会裁掉超出部分，用于突出局部。
- **旋转**：用顺时针或逆时针 90° 操作修正方向。
- **水平 / 垂直翻转**：改变图像朝向，特别注意文字会镜像。
- **重置变换**：恢复该图的变换，再重新安排。

拖动图片本体或控制柄时，松开左键提交；尚未松开时按 **Esc** 取消这一笔，原有排版保留。已松开后要撤回该图的变换，可选中它使用 **重置变换**。

预览区滚轮改变观看缩放，中键拖动平移画布；它们不等同于单张图片的排版缩放。点击 **适应画布**，或在预览获得焦点时按 **F / Home**，可重新看全组合图。

## 替换、删除与清空

把指针移到缩略图上，显示 **替换图像** 和 **删除图像** 图标；悬停核对名称后再操作。点击 **替换图像** 选择新文件；取消文件选择或新文件读取失败时，原图保留。替换成功后，该项的旋转、翻转、位置和缩放恢复默认，重新调整并检查。**删除图像** 会直接移除该项，并重置后续项的位置与缩放；检查顺序、网格和裁切是否仍符合预期。

**全部清空** 会提示确认，当前组合会被移除。还需要当前结果时先保存；关闭窗口或点击底部 **取消** 时，已有图片的会话会询问是否放弃，选择取消可返回继续排版。

部分图片无法加载时，阅读错误中的文件列表，再重新添加可用文件。拼接尺寸过大或导出失败时，保留窗口，减少素材数量或输出规模后重试。需要按纸张整理成文档，转到[图片转 PDF](./pdf.mdx)。
