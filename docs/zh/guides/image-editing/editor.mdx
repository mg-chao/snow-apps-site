# 打开图片与裁剪行列

图像编辑用于处理已有图片，也适合继续整理滚动长截图。它提供熟悉的标注工具，并能删除图中多余的整行或整列条带，把两侧剩余内容接起来。

![标注前的图片：Start 和 Target 两个浅色框，尚未添加箭头或说明文字](/images/guides/img-editor-original-input.webp)

*打开的原图：保留两块内容，准备说明它们的关系。*

![标注后保存的图片：红色箭头从 Start 指向 Target，矩形框突出起点，下方有 Step 1 说明](/images/guides/img-editor-annotated-output.webp)

*加上箭头、矩形和文字后，保存为新图片；也可以把同一结果固定到桌面旁边。这里展示标注结果，后面的裁剪教程用于删除整行或整列内容。*

## 打开并查看图片

1. 在主窗口的 **搜索功能** 中输入 **编辑选中的图像**，从下拉结果选择同名项。使用键盘时，可用向下键进入结果，再按 Enter 选择；页面会定位并突出显示对应动作行。
2. 再单击 **编辑选中的图像** 动作行的标题或空白区域，打开图像编辑。右侧显示按键或“未设置”的按钮用于配置快捷键；直接点击动作无须先分配按键。没有取得可用的选中文件时，会打开空窗口。
3. 在空窗口点击 **添加图像**，在文件对话框选择一张图片并打开。等待“正在加载图像…”结束，确认图片出现在画布中；在文件对话框取消则保留空窗口。
4. 找到画布**底部中央**的两个缩放按钮：左侧是 **适应窗口**，右侧是 **以实际大小查看（100%）**，悬停图标可核对名称。点右侧检查像素细节，点左侧恢复整图查看；100% 不一定比适应窗口更大，取决于原图和窗口大小。画布缩放不会改变导出图片的像素尺寸。
5. 从标注工具条选择图形、箭头、文字或滤镜，按各工具教程编辑；需要留在桌面上对照时，使用 **固定到屏幕**，方法见[图片贴图](../pinning/image.md#从图像编辑窗口固定)。

### 添加说明，再保存或固定

1. 图片载入后选择 **箭头**，从 Start 一侧按住左键拖向 Target，松开完成。需要规则框线时切换 **矩形**，拖出包围重点内容的范围。
2. 选择 **文字**，单击图片中的位置并输入 `Step 1`。按 **Esc** 结束输入，再按 **V** 切换到 **选择元素**，点击空白处清除选择，然后直接按住未选中的文字拖到目标位置；详见[文字移动](../annotations/text.mdx#移动缩放与旋转)。选中矩形后可拖控制柄调整大小。
3. 使用 **保存为文件**，选择目录、一个新文件名和 PNG 等需要的格式，单击 **保存**。重新打开保存文件，检查箭头方向、文字和边缘。macOS 编辑窗口默认 **Command+S** 保存；自定义过时以应用快捷键为准。
4. 要把同一结果留在桌面，使用 **固定到屏幕**；macOS 编辑窗口默认 **Command+F**。新贴图显示当前编辑结果，仍需文件时再从贴图保存。贴图操作见[图片与剪贴板贴图](../pinning/image.md)。

### 拖入与一次打开多张图片

也可以把图片文件拖到空窗口的提示区域；一次添加多张图片时，每张在独立窗口中打开。图片显示后，即可用下面的裁剪操作删除多余条带。

## 从文件管理器的所选图片开始

在主界面的 **全局快捷键** 中找到 **编辑选中的图像** 并设置一个没有冲突的全局快捷键；该动作没有预设按键，不能直接套用截图快捷键。然后回到系统文件管理器，选中一张或多张图片文件，按刚设置的快捷键，每张图片分别进入独立图像编辑窗口。

没有选中图片时，动作打开空窗口，可以继续用窗口中的选图入口添加素材。macOS 如果提示 Snow Shot 请求控制 Finder 来读取所选文件，按系统提示授予相应自动化权限后重试。快捷键的配置与冲突处理见[快捷键设置](../settings/shortcuts.mdx)。

## 垂直裁剪：去掉一段横向条带

垂直裁剪沿图像高度方向删除整行像素。它位于图像编辑器的**浮动主工具条**，与画布底部的适应窗口 / 100% 控件不同；悬停图标确认名称为 **垂直裁剪**。行、列裁剪都没有默认专用快捷键。

1. 等待图片加载完成，结束文字输入，再点击 **垂直裁剪**。按钮显示激活状态；指针进入图片时出现定位线。
2. 在图片内、要删除条带的上边缘按住左键，向下拖到下边缘；也可从下向上拖。红色预览横跨整张图片宽度，两条边界线之间显示要删除的源图像像素数 **N px**。
3. 检查整条带没有包含要保留的内容，**松开左键即提交**，不需要再点确定。处理后上下内容接合，图片高度减少 N 像素，宽度不变。
4. 等待画布和工具条恢复可用，再检查接合处；误删原图内容时使用 **撤销**。

它删除条带，不保留框内区域；不能一次删掉整张图片的高度，零高度的范围也不会改变图片。预览不合适时，在按住左键期间按 **Esc**，再松开鼠标：本次拖动取消，仍留在垂直裁剪工具，可以重画。要退出裁剪，再点击当前激活的裁剪按钮，返回平移模式。

## 水平裁剪：去掉一段纵向条带

水平裁剪沿图像宽度方向删除整列像素，适合去除中间空列或多余侧栏。

1. 在同一浮动主工具条悬停确认 **水平裁剪**，单击使其激活。
2. 在图片内按住左键，从要删除条带的一侧拖到另一侧，向左或向右均可。红色预览贯穿图片高度，**N px** 表示要删除的列数；检查上、下各处有没有同列中需要保留的内容。
3. 松开左键即提交。等待处理完成，检查左右内容接合；图片宽度减少 N 像素，高度不变。

不能删掉整张图片的宽度，零宽度范围也不会改变图片。取消当前预览时，按 **Esc** 后再松开鼠标，仍留在水平裁剪工具；再点击激活的按钮才退出裁剪、返回平移。

## 撤销、输出与后续处理

裁剪与标注按操作顺序进入同一编辑历史。在图片画布上点击 **撤销**，或使用默认的 Windows **Ctrl+Z** / macOS **Command+Z**，退回最近一步；**重做**默认 Windows **Ctrl+Y** / macOS **Command+Y**。刚完成裁剪后直接撤销会恢复条带和原图尺寸，重做会再次删除；如果裁剪后又画了一笔，第一次撤销先退掉这笔，下一次才恢复裁剪。

正在输入标注文字时，撤销处理的是文字编辑，先按 Esc 结束输入再操作画布。识别文字的编辑状态也有自己的文字历史；要撤销图片裁剪，先点击裁剪工具回到图片画布。裁剪或恢复条带时等待画布和工具条恢复可用，再继续编辑、撤销或导出。

尽量先裁剪，再添加标注。裁剪底图时，本次添加的可编辑标注会保留原位置；裁剪后检查箭头指向和文字位置，必要时重新移动。重新打开已保存的图片时，原有标注已是图片内容，会和底图一起裁剪。

工具条可把当前结果复制到剪贴板、保存为文件或快速保存，也可进入文本、表格和条码识别。识别处理的是当前编辑结果，先检查裁剪与标注是否合适。

关闭有未保存编辑的窗口时，应用提示 **放弃更改** 或 **继续编辑**。需要成品图时先保存，避免把关闭窗口当作保存动作。

## Windows 文件的“使用 Snow Shot 编辑”

Windows 系统集成的 **使用 Snow Shot 编辑** 还会打开新的贴图窗口。设置中的 **打开编辑时启用标注模式** 控制这些新窗口是否自动进入标注：开启后可直接画写，关闭后先从贴图窗口切入标注模式再使用工具。

这项设置属于 Windows 的文件编辑集成，不改变独立图像编辑窗口的裁剪流程。相关操作见[贴图](../pinning/image.md)与[系统集成](../settings/network-integration.md)。

## 图片无法加载或太大

出现无法加载提示时，先确认文件是应用支持的图像格式并且没有损坏；可在其他图像软件确认能否打开，再重新添加。提示图片太大或内存不足时，关闭其他大型图像窗口，或先使用较小的图像。

**画面缩小但文件尺寸没变**：这是查看缩放。要裁去内容，用垂直或水平裁剪；要拼排并调整图像在画布中的比例，使用[图片拼接](./collage.mdx)。
