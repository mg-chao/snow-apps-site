# LaTeX 公式识别

论文和课件里的公式可以用**LaTeX 公式识别**转成源码，再粘贴到支持 LaTeX 的编辑器。它提供公式预览，便于检查上下标、分数和括号是否对应。此功能需要完整版和可用的识别服务。

![公式识别教学示意：公式图像转成源码，修改分母后重新查看渲染结果](/images/guides/rec-formula.svg)

*操作示意。源码与预览是同一结果的两种表达，复制时应确认目标软件需要的语法。*

## 取得公式源码

1. 使用截图快捷键（Windows 默认 **F1**，macOS 默认 **Control+1**），框住一条完整公式。把上下标、分数线、积分上下限和两端括号都留在选区中。
2. 在截图工具栏选择**LaTeX 公式识别**，等待处理状态结束。
3. 在结果属性栏的**识别模型**中，可选择**LaTeX 专用模型**或可用视觉模型。选择视觉模型前，应在[服务配置](../translation/services.md)中准备实际支持图片的模型。
4. 对照原图检查返回的源码和公式预览。专用模型提示输入超过 4K 时，改截单条公式或更小区域。

## 校正与预览

在**LaTeX 公式源码**区域修改文字，预览会在内容更新后重新渲染。修改前先找出最小错误，例如把 `x_1` 误认成 `x_l`，或遗漏一侧花括号；只改对应部分更容易判断结果。

- 分数结构不对：检查 `\frac{...}{...}` 的两组花括号是否完整。
- 上下标范围不对：检查 `_`、`^` 后需要整体组合的内容有没有放进花括号。
- 识别结果正确但预览异常：查看预览提示。应用内渲染器的能力和目标 LaTeX 编辑器可能不同，先复制源码到目标环境核对。

工具栏**撤销**和**重做**可以恢复源码编辑。它们与重新识别不同，不会重新向服务提交图片。**显示原图**用于核对输入图像，公式预览用于检查当前源码，两者不要混淆。

## 复制与保存

1. 要使用整条公式，取消局部选择后使用工具栏**复制到剪贴板**；只要某个表达式，在源码中选择相应部分再复制。
2. 粘贴到目标编辑器后，按它要求的行内或独立公式环境放置源码。Snow Shot 的预览正确不代表目标软件已进入公式模式。
3. 要保留源码文件，使用**保存为文件**，选择目录和名称，保存为 **.txt**。文件包含公式文本，后续可以在文本编辑器中继续修改。

## 遇到问题时

| 提示或现象 | 下一步 |
|---|---|
| 无法预览此公式，请检查 LaTeX 源码 | 检查括号配对、命令和未闭合结构，逐步撤销最近修改定位问题 |
| 超过公式预览限制 | 缩短公式，只保留需要的部分；复杂内容到目标编辑器中处理 |
| 公式渲染器不可用 | 先复制源码到自己的公式工具；重启应用后重试预览 |
| 识别服务或模型不可用 | 检查服务配置，选择另一个可用模型，再使用**重试** |
| 内容被识别成多条或缺少上下标 | 重新框选单条完整公式，增大原应用显示比例后再截 |
