# 图片转换为 Markdown 与 HTML

当图片中同时有标题、段落、列表和表格时，**转换为 Markdown**与**转换为 HTML**用于重新组织这些内容。结果由视觉模型生成，校对文字和结构后再用于正式文档。完整版提供这两个工具，Mini 不包含它们。

![图片转换教学示意：同一段文档选择 Markdown 或 HTML，得到不同格式的文档及源码文本](/images/guides/rec-conversion.svg)

*操作示意。示例展示格式差异，不表示模型一定保留原图的全部版式。*

## 准备视觉模型

先在**设置 → 网络与连接 → 自定义 AI 模型**配置模型，启用**视觉支持**，并确认服务端的实际模型能接收图像。勾选该项只让模型出现在相关能力的选择中，不会改变远端模型本身。详细字段见[翻译服务与自定义模型](../translation/services.md)。

转换会把选定图片发送给所选模型服务，使用前确认服务可以访问。图片转换与本地文字识别使用不同的处理方式，需要单独准备模型服务。

## 完成一次转换

1. 使用截图快捷键（Windows 默认 **F1**，macOS 默认 **Control+1**），框选要转成文档的内容。保留完整段落和表格边界，避免把旁边的导航、广告或另一篇文章一起选中。
2. 在截图工具栏选择**转换为 Markdown**，或选择**转换为 HTML**。Markdown 适合继续放入笔记、仓库文档；HTML 适合需要网页文档结构的场合。
3. 要更换模型，单击结果属性栏的**设置**，在**图像转换设置 → 视觉模型**中选择已准备好的模型，再单击**确定**。更换后会重新转换；单击**取消**则不保存本次选择。若提示没有可用模型，先完成模型配置，再回到结果单击**重试**。处理时观察结果区域逐渐出现的内容，等待完成后再使用。
4. 对照原图检查标题层级、列表顺序、表格内容和数字。转换结果可能重新排版，不应把预览外观当成对原图的精确复制。

## 预览复制与保存

结果区域显示文档预览，便于检查段落和结构。预览不是源码编辑器；需要修正生成文档时，把结果复制或保存到目标编辑器中继续处理。

- **复制选中部分**：在预览中选择所需文字，右键**复制**，再到目标应用粘贴检查范围。
- **复制完整结果**：取消局部文字选择后使用复制。不同目标应用可能采用剪贴板里的不同格式，粘贴后检查标题与表格。
- **保存文档**：单击**保存为文件**，选择目录和文件名。Markdown 保存为 **.md**，HTML 保存为 **.html**。
- **保留生成源码**：保存同时产生同名 **.txt** 配套文件。一起检查这两个输出文件；已有同名文件时，替换确认会覆盖相应文件。

如果需要精确整理电子表格单元格，使用[表格识别](./table.mdx)并导出 XLSX 更方便。如果只需要一段文字，用[文本识别](./text.md)即可。

## 失败时重新处理

没有可选视觉模型时，回到模型配置检查“视觉支持”和模型是否仍然存在。模型列表中出现名称，不能证明服务端已接受图像输入。

网络、认证或模型返回错误时，先按提示检查 API 地址、密钥、模型 ID 和代理，再单击结果区域的**重试**。如果输出缺失内容，缩小到单个文档区域重新截图；反复重试同一张低清晰度图片不一定改善结果。

离开当前截图可用**取消截图**。要保留已有内容，退出前先复制或保存。
