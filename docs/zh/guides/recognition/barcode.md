# 条码与二维码识别

**条码识别**读取屏幕上的条形码、二维码内容，适合提取图片中的网址或编号。识别内容不等于确认它的真实性；打开链接前先检查地址。此工具在完整版中提供，Mini 不包含此入口。

![条码识别教学示意：完整框选条码、读出内容，再选择复制或打开链接](/images/guides/rec-barcode.svg)

*操作示意。图中方块用于说明输入范围，不是可扫描二维码。*

## 识别并取得内容

1. 把条码完整显示在屏幕上。使用截图快捷键（Windows 默认 **F1**，macOS 默认 **Control+1**），拖出包含整个条码及少量周围留白的选区，避免只截取部分方块或线条。
2. 在截图工具栏找到表格与条码的工具组，展开选项，选择**条码识别**。组按钮显示的是当前或上次使用的工具，不能仅凭位置判断。
3. 等待识别结束。成功时结果区域显示读出的文本；选区包含多个可识别条码时，逐项检查各个结果，确认要使用的是哪一项。
4. 若只需要一个结果，在对应文字中拖动选择，再右键**复制**；要全部内容可使用**全选**后复制。

## 自动识别二维码与显示标记

完整版也可以在确认截图选区后自动发现二维码：

1. 在**设置 → 截图**的交互设置中开启**自动识别二维码**，重新截图并确认包含完整二维码的选区。
2. 保持**移动**工具状态，等待选区内可识别二维码出现圆形标记。单击目标二维码上的标记，打开文字气泡；存在多个二维码时逐个检查。
3. 气泡中单击**复制文本**会复制选中文字；没有局部选择时复制该二维码的全部内容，并结束截图。有效网址还会提供**打开链接**；打开成功后结束截图，失败时气泡显示错误供你处理。
4. 不想让标记遮住画面时，在移动工具的属性栏单击**显示二维码**，切换这些检测标记的可见状态。

“显示二维码”控制已检测标记，不会生成新的二维码。没有出现标记时，检查自动识别开关、当前工具状态和图像清晰度，也可改用上面的手动条码识别查看结果。

![自动二维码教学示意：确认选区后出现检测标记，单击标记显示内容气泡，复制后结束截图](/images/guides/rec-autoqr.svg)

*操作示意。圆形标记是自动检测入口，气泡中的复制与打开会结束当前截图。*

## 复制与打开链接

- **复制内容**：在结果上右键选择**复制**，再粘贴到文本编辑器。先检查是否包含了多个条码的内容或额外换行。
- **保存结果**：使用工具栏**保存为文件**，在保存对话框中选择位置，结果以 **.txt** 文本文件保存。它保存读出的内容，不是二维码图片。
- **打开链接**：结果中的可点击网址可交给系统默认浏览器打开。只有识别为链接的部分会出现相应交互；普通编号仍按文字复制。
- **保留条码图像**：如果目的是保存原始条码，退出识别结果并按截图输出流程保存原图，不要把 TXT 当作图像文件。

## 没有识别结果时

出现“未识别到条码”时，先检查有没有完整包含边界，以及图像是否经过压缩、模糊、遮挡或强烈透视。可以在原应用放大条码后重新截图。

如果画面中有很多条码，先只截一个，确认它能被读取，再扩大范围。手动放大截图不能补回原图中已经丢失的细节。

服务或请求出现错误时，按结果区域的**重试**重新处理当前输入；输入本身不清晰时应重新框选。退出当前截图后重新进入会得到新的输入范围。
