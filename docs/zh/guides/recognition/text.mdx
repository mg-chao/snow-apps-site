# 截图转文字：本地 OCR 识别与复制教程

在 Windows 和 macOS 使用 Snow Shot 的**文本识别**，可以把截图或已有图片中的文字提取为可复制文本。识别后先对照原图校正，再复制到目标应用；从图像编辑器识别图片时，还能直接保存 TXT。普通 OCR 在本机处理，首次使用可能需要准备识别组件。Mini 默认隐藏截图工具栏中的文本识别，可从主窗口动作进入、加入工具栏或配置独立快捷动作，见[OCR 模型与离线准备](./models.mdx)。

![文本识别教学示意：框选清晰文字、校对原图、修正结果并复制](/images/guides/rec-text.svg)

*操作示意。示例原文是 `012`；左侧识别为 `O12`，右侧对照原文修正为 `012` 后再整理换行。*

## 提取一段文字

1. 让待识别内容完整显示在屏幕上。使用截图快捷键（Windows 默认 **F1**，macOS 默认 **Control+1**） 进入截图，在文字外围拖出选区；选区中保留完整行，避免截断字符。
2. 在选区工具栏找到**文本识别**。若工具栏分组或顺序被修改，悬停图标查看提示文字；单击后进入识别状态。
3. 首次出现“正在准备文本识别组件”时保持联网，等待进度结束；已经准备好资源时会直接识别。结果出现后先检查文字，再复制到目标应用。
4. 若只需要其中几行，在文字结果中拖动选中它们，再复制；需要整段时先取消局部选择，使用工具栏**复制到剪贴板**。

也可以不分配独立快捷键：在主窗口的**搜索功能**输入“文本识别”，选中对应结果后，页面会定位到**全局快捷键**中的**文本识别**动作。单击这一行的标题或空白区域进入截图，确认选区后直接进行识别。右侧显示快捷键或“未设置”的虚线按钮用于配置按键；搜索结果本身只负责定位，不会立即启动识别。

识别过程中不要把“下载组件”当作识别失败而反复点击。结束当前截图可用工具栏**取消截图**；再次截取更清晰、更小的区域可以重新开始。

## 识别已有图片并保存文字

手边已有图片文件时，可以直接在图像编辑器中提取文字。先检查原图是否清楚、文字完整；需要一边校对一边看原图时，也可在系统看图应用中打开原文件。

Mini 默认隐藏图像编辑器的**文本识别**按钮。图片载入、画布获得焦点后，可直接按 **Ctrl+D**（macOS 为 **Command+D**）识别。需要显示按钮时，打开**设置 → 固定到屏幕 → 操作工具栏 → 固定到屏幕工具栏设置**，把**文本识别**从**隐藏的工具**拖到可见位置；这里的布局与截图工具栏分开设置。

1. 在主窗口的**搜索功能**输入**编辑选中的图像**，选中搜索结果定位动作行，再单击该行的标题或空白区域。没有取得可用的选中文件时，会打开空的图像编辑窗口。
2. 单击**添加图像**，在文件对话框选一张图片并打开。等待加载结束，确认画布显示的是要识别的图片；在文件对话框取消则不载入新文件。
3. 在图像编辑工具条单击**文本识别**。macOS 默认也可在图像画布获得焦点时按 **Command+D**；正在输入文字时，局部工具快捷键可能不会响应，应使用工具条按钮。等待图片中的文字出现在结果区域。
4. 结果会自动进入可编辑文字状态。对照图片检查文字，在结果中选中需要修改的字词并输入内容。练习时可把示例中的 `Target` 改成 `Goal`；实际校对时，让文字与原图一致。macOS 文本编辑中按 **Command+Z** 撤销，按 **Command+Shift+Z** 重做。
5. 只要一部分时，在结果中选中所需文字后复制；要全部内容时，先全选再复制。macOS 分别使用 **Command+C** 和 **Command+A**。到文本编辑器粘贴，检查得到的是所需片段还是完整段落。
6. 保持文字识别结果，单击工具条**保存为文件**，在保存对话框选择目录、输入文件名并保存为 **.txt**。这里保存的是文字，不是原图；取消保存会保留当前文字编辑，可以继续修改或再次保存。
7. 在系统文本编辑器中重新打开 TXT，检查文字、换行及保存的内容。示例保存为 `recognized-goal.txt`，打开后是 `Start` 和 `Goal` 两行。

图像编辑器的识别结果不提供**显示原图**切换；下面“校对与编辑”中的原图按钮用于截图识别流程。需要保留图片本身时，按[图像编辑](../image-editing/editor.mdx)的图片保存流程操作；保存 TXT 不会覆盖原始图片。

## 校对与编辑

从截图工具栏进入识别时，可按下面的方法显示原图并校正。识别结果里的数字、英文大小写、路径分隔符和形近字需要对照原图检查。尤其是命令、金额、账号，复制前逐项核对。

1. 在识别工具的属性栏单击**显示原图**，暂时隐藏文字结果、查看输入图像；再单击返回结果。要在结果旁保留单独的原图参照，打开**设置 → 文本识别与翻译 → 识别结果 → 显示原图预览**。这是另一个显示选项，不是“显示原图”按钮的默认状态。Mini 的设置页名为**文本识别**。
2. 单击属性栏**编辑**，在可编辑的文字结果中定位错误，删除错误字符并输入正确内容。修改只影响当前识别结果，不会修改屏幕里的原文。
3. 修改后使用工具栏**撤销**退回上一步，或用**重做**恢复撤销的操作。先将焦点留在当前结果里，避免快捷键被其他应用接收。
4. 若要舍弃当前文字整理，单击**重置**恢复本次最初识别出的文字，同时清除当前格式与标点选择；它不会重新识别图片。误点重置后可用**撤销**恢复重置前的文字。需要更换原图范围时退出当前截图，再框选。

## 调整格式与标点

属性栏的**格式**和**标点符号**用于整理整段识别文字，不只作用于局部选中文字。选择规则后会进入文字编辑并应用结果；清除选择或选择“无”可取消对应转换。先选好格式，再逐字校对，尤其使用智能排版后要重新检查手工改过的内容；效果不合适可用**撤销**恢复。工具不会判断命令中的标点是否应被改动。

| 选项 | 效果与适用场景 |
|---|---|
| 无 | 不增加对应的排版或标点转换，适合保留原始识别结果 |
| 保留换行 | 保留文本行的边界，适合日志、地址和逐行清单 |
| 移除换行 | 把图片中人为折行的连续内容连起来；复制后检查段落边界 |
| 智能排版 | 按识别行的关系整理段落；适合正文，仍需核对标题与列表 |
| 半角 | 将可转换标点整理为半角形式；用于代码前仍应核对 |
| 全角 | 将可转换标点整理为全角形式；适合部分中文排版需求 |

常用规则可在**设置 → 文本识别与翻译 → 识别结果**设置**默认格式**和**默认标点**；Mini 中对应页面名为**文本识别**。默认规则在编辑或复制识别文字时使用；先用一段样例确认输出符合自己的用途。

## 复制文字与保存图片

**复制到剪贴板**可以把当前文字结果带到文本编辑器；存在局部文字选择时先确认复制范围。在目标应用粘贴一次，就能检查有没有多余换行或遗漏字符。

从截图工具栏识别时，**保存为文件**需结合当前结果和输出设置理解：“将识别结果保存为图像”选项控制截图导出时是否把显示的文字结果渲染到图片里。需要可编辑文字时，可以复制到文本编辑器后保存；从已有图片进入图像编辑器识别时，可按上面的步骤直接保存 TXT。需要表格结构时请用[表格识别](./table.mdx)。

![保存为文件图标、保持文字识别结果与TXT保存或取消的去向](/images/guides/rec-editor-save-control.svg)

*悬停核对保存为文件；图像编辑器中保持文字识别结果时，保存TXT后重新打开核对。*

## 识别文字的背景与高亮

下面的背景与高亮用于截图识别；图像编辑器的独立文字结果不会显示这些原图叠加效果。

在**设置 → 文本识别与翻译 → 文本背景**（Mini 对应**文本识别**页）中，可以调整识别结果怎样放在原图上：

- **填充样式**选择**模糊**或**背景填充**，决定识别文字后面的区域怎样处理。先用同一段带背景的文字对照，选择能看清结果的方式；它不是标注工具里的马赛克或模糊滤镜。
- **显示文本高亮**在识别结果周围增加遮罩，帮助突出文字。开启后重新查看结果与原图的区别；不需要额外突出时关闭。

![识别文字背景教学示意：模糊和平色背景填充作为两种显示处理，文字仍需校对](/images/guides/rec-background.svg)

*操作示意。对比文字背景的两种显示处理。*

更改显示样式不会自动修正错字。仍需按“校对与编辑”逐项检查，再取得文字或渲染图片。

## 文本识别后自动执行

希望识别完成就复制，或直接进入校正时，打开**设置 → 截图 → 操作方式 → 文本识别后自动执行**。先选择一个行为，再用不含敏感内容的短句测试；已有自定义配置会改变前文“等待结果后手动复制”的流程。

| 选项 | 识别成功后发生什么 |
|---|---|
| 不执行操作 | 保持结果，等你检查后手动编辑或复制 |
| 复制文本 | 自动把识别文字放入剪贴板，保持截图会话 |
| 复制文本并结束截图 | 自动复制文字后结束当前截图，可直接到其他应用粘贴 |
| 复制文本（全局） | 仅从独立的全局“文本识别”动作进入时自动复制；普通截图工具栏进入识别时不执行这项自动复制 |
| 复制文本并结束截图（全局） | 仅从独立全局识别动作进入时，自动复制并结束截图 |
| 启用编辑模式 | 识别结果出现后进入文字编辑，方便立即修正 |

这里的“全局”限定的是**入口**，不是把 C 等普通按键变成系统范围快捷键。独立的“文本识别后复制”动作本来就用于复制后结束，与普通工具栏的文本识别要分开选择。

![文本识别后自动执行教学示意：普通入口与全局识别入口分别使用自动行为，复制和结束截图是两个结果](/images/guides/rec-auto-action.svg)

*操作示意。想先校对再使用文字时，选择不执行操作或启用编辑模式。*

如果识别完成后截图突然关闭，先查看是否选中了“复制文本并结束截图”；如果只在独立识别入口生效，检查是否选了带“全局”的选项。确认剪贴板内容后再继续任务，避免把上一轮结果当成新的识别文字。

## 遇到问题时

| 现象 | 处理方法 |
|---|---|
| 一直提示准备组件 | 检查网络连接和代理，让首次资源准备完成；离线环境要提前下载 |
| 文字缺失或顺序不理想 | 缩小选区，完整包含目标行；放大原应用文字后重新截图；再考虑调整检测策略 |
| 提示截图超过 4K | 缩小识别范围或分块识别，避免一次提交整张超长图 |
| 本机识别速度慢 | 在 OCR 模型与性能中比较模型大小、检测缩放和常驻设置，不要同时改动所有选项 |
| 图片里有表格但结果变成普通文字 | 改用表格识别，普通文字识别不会替代单元格结构编辑 |
