# 图片转换为 Markdown 与 HTML

当图片中同时有标题、段落、列表和表格时，**转换为 Markdown**与**转换为 HTML**用于重新组织这些内容。结果由视觉模型生成，校对文字和结构后再用于正式文档。完整版提供这两个工具，Mini 不包含它们。

![图片转换教学示意：同一段文档选择 Markdown 或 HTML，得到不同格式的文档及源码文本](/images/guides/rec-conversion.svg)

*操作示意。示例展示格式差异，不表示模型一定保留原图的全部版式。*

## 准备视觉模型

可以使用列表中可用的 Snow Shot 视觉模型，也可以使用自己的模型服务。自定义服务需先在**设置 → 网络与连接 → 自定义 AI 模型**配置模型，启用**视觉支持**，并确认服务端的实际模型能接收图像。勾选该项只让模型出现在相关能力的选择中，不会改变远端模型本身。详细字段见[翻译服务与自定义模型](../translation/services.md)。

转换会把选定图片发送给所选模型服务，使用前确认服务可以访问。图片转换与本地文字识别使用不同的处理方式，需要单独准备模型服务。

## 完成一次转换

1. 使用截图快捷键（Windows 默认 **F1**，macOS 默认 **Control+1**），框选要转成文档的内容。保留完整段落和表格边界，避免把旁边的导航、广告或另一篇文章一起选中。
2. 在截图工具栏选择**转换为 Markdown**，或选择**转换为 HTML**。Markdown 适合继续放入笔记、仓库文档；HTML 适合需要网页文档结构的场合。
3. 要更换模型，单击结果属性栏的**设置**，在**图像转换设置 → 视觉模型**中选择可用模型，再单击**确定**，回到结果等待所选模型的内容；单击**取消**保留原选择。若设置窗口提示模型列表加载失败，先检查服务与网络，再单击这个窗口里的**重试**刷新列表。有可用模型后才能确定选择。没有另外选择模型时，会使用可用视觉模型开始处理。
4. 观察结果逐渐出现，等待处理结束；没有错误提示后，再对照原图检查标题层级、列表顺序、表格内容和数字。转换结果可能重新排版，不应把预览外观当成对原图的精确复制。

![属性栏设置打开图像转换设置。列表加载失败时，检查连接后用这个窗口里的重试刷新；选可用视觉模型后确定。取消只放弃本次选择，不是结果重试。](/images/guides/rec-conversion-workflow-1.svg)

*属性栏设置打开图像转换设置。列表加载失败时，检查连接后用这个窗口里的重试刷新；选可用视觉模型后确定。取消只放弃本次选择，不是结果重试。*

## 预览复制与保存

结果区域显示文档预览，便于检查段落和结构。预览不是源码编辑器；需要修正生成文档时，把结果复制或保存到目标编辑器中继续处理。

- **复制选中部分**：在预览中选择所需文字，右键**复制**。复制的是选中部分的可见内容，不是对应的 Markdown 或 HTML 源码片段；到目标应用粘贴检查范围。
- **复制完整源码**：使用工具栏**复制到剪贴板**，会复制完整生成源码，不受预览中的局部文字选择影响。Markdown 包含标题或列表等语法；HTML 同时提供 HTML 格式，目标应用可能粘成排版内容。需要检查源码时粘贴到纯文本编辑器。预览中没有局部选择时，右键**复制**也取得完整源码。
- **保存文档**：单击**保存为文件**，选择目录和文件名，保存完整生成文档，不受预览选区影响。Markdown 为 **.md**，HTML 为 **.html**。取消保存保留当前结果；成功保存后结束当前截图。
- **保留生成源码**：保存同时产生同名 **.txt** 配套文件。保存后在目标编辑器打开文档，再用文本编辑器打开 TXT 核对源码。已有同名文件时，替换确认会覆盖列出的对应文件；选择**取消**则不替换。

如果既要复制又要保存，先在预览中右键复制所需内容，再保存文档。保存后的文件可在目标编辑器继续修正。

如果需要精确整理电子表格单元格，使用[表格识别](./table.mdx)并导出 XLSX 更方便。如果只需要一段文字，用[文本识别](./text.mdx)即可。

## 失败时重新处理

没有可选视觉模型时，回到模型配置检查“视觉支持”和模型是否仍然存在。模型列表中出现名称，不能证明服务端已接受图像输入。

网络、认证或模型返回错误时，先按提示检查所选服务；自定义模型还需核对 API 地址、密钥和模型 ID，连接问题再检查代理。结果出现**结果不完整**时，即使仍看得到部分内容，也不代表转换完成。若要保留它，先在预览中右键复制，再单击结果区域的**重试**；重试会清空当前生成内容，从头处理同一图片。输入本身不完整时，缩小到单个文档区域重新截图；反复重试同一张低清晰度图片不一定改善结果。

![出现结果不完整时，可先在预览右键复制保留现有内容。结果区域重试会清空这一轮生成内容，从头处理同一张图片。](/images/guides/rec-conversion-workflow-3.svg)

*出现结果不完整时，可先在预览右键复制保留现有内容。结果区域重试会清空这一轮生成内容，从头处理同一张图片。*

离开当前截图可用**取消截图**。要保留已有内容，退出前先复制或保存。
