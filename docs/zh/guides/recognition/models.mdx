# OCR 模型与离线准备

文字识别的等待时间包括组件准备、模型加载和实际识别。先保证资源完整，再按“速度还是细节更重要”选择模型。这里的模型设置用于本地文字识别；表格、公式和翻译有各自的服务要求。

![OCR 模型教学示意：准备资源、选择模型、比较同一样例的速度与准确性](/images/guides/rec-models.svg)

*操作示意。不要仅凭模型大小判断自己的文字样例是否能被正确识别。*

## 离线前准备

| 安装方式 | 断网前需要完成的步骤 |
|---|---|
| Windows 完整版离线安装包 | 安装包包含默认 OCR 资源；安装后用实际需要的文字样例完成一次识别 |
| 完整版在线安装包 | 联网安装所需组件；进入文本识别，等待首次资源准备结束 |
| Mini | 从主窗口的文本识别动作进入，或先加入截图工具栏、配置独立识别快捷动作；联网准备资源后运行样例 |

Mini 中添加入口：打开**设置 → 截图 → 操作工具栏 → 截图工具栏设置**，把“隐藏的工具”中的**文本识别**拖到可见工具位置；也可在**全局快捷键**给**文本识别**绑定一个独立快捷动作。加入后重新截图，确认工具栏已经出现文本识别按钮。

只想先试用时，无须分配按键。在主窗口的**搜索功能**搜索“文本识别”，选结果定位到全局快捷键页，再单击**文本识别**动作行的标题或空白区域。右侧的“未设置”按钮才是按键配置入口；确认截图选区后会直接识别。

如果要切换到其他大小的模型，在联网时切换并执行一次识别。确认准备进度结束后，再断网重复同一任务。普通截图成功不能证明 OCR 资源已准备好。

遇到一般资源准备错误，先恢复网络、检查**设置 → 网络与连接**里的代理，然后结束当前截图并重新进入文本识别。若提示 Mac 捆绑的识别运行时损坏或不兼容，需要重新安装适合这台 Mac 的 Snow Shot；若提示修复 Microsoft Store 安装，则从该安装渠道修复或重装。单纯恢复网络不能替代这些安装修复。不要通过删除未知数据目录来尝试修复。

Mini 中对应的设置页名为**文本识别**，其模型与输出设置按同样方法操作。

## 选择模型

1. 打开主界面**设置 → 文本识别与翻译**，展开**OCR 模型与性能**。
2. 在**模型类型**中选择**超小型 V6**、**小型 V6**或**中型 V6**。默认配置为小型 V6。
3. 设置会保存，无须另点“保存”。结束当前截图，再对同一张原图重新框选相同范围，运行文本识别、记录等待时间并校对结果。每次换模型后都重新发起一次截图识别，避免把已有结果或截图范围差异当作新模型的表现。

较小模型适合优先减少运算量的场景；更大模型需要更多资源。最终应按自己经常识别的字体、字号和版式判断，不能保证更换模型必然修正某个字。

![模型大小选项，以及资源已齐与缺少资源的识别路径](/images/guides/rec-model-controls-1.svg)

*选好模型后，用新截图识别同一样例。*

## 检测与处理策略

**文本检测缩放**决定识别前怎样调整图像：

- **限制长边（更快）**：约束较长的一边，适合优先降低处理开销。很小的字可能需要先在原应用放大再截图。
- **放大短边（更多细节）**：放大较短的一边，可能找到较小文字，也会增加处理量。

**文本检测处理**可选**准确优先**和**速度优先**。速度优先会减少部分短文本的计算，并可能改变结果。新配置默认使用**限制长边（更快）**与**准确优先**。切换后重新截图识别同一段文本，确认没有因提速而漏掉需要的内容；要恢复比较基准，选回先前的规则。

![文本检测缩放与处理策略的选项](/images/guides/rec-model-controls-2.svg)

*每次只改一个选项，再检查新的识别结果。*

## 降低等待时间

| 设置 | 改变什么 | 使用时注意 |
|---|---|---|
| 硬件加速 | 可用时使用 GPU；不可用时回到 CPU | 开启不代表当前设备一定在用 GPU |
| 常驻识别进程 | 保留识别进程，减少下一次启动等待 | 空闲时也会占用内存 |
| 模型热启动 | 预先加载所选模型，减少下一次模型加载等待 | 依赖常驻进程，并增加内存占用 |

新配置默认关闭**硬件加速**与**模型热启动**；**常驻识别进程**在完整版默认开启，在 Mini 默认关闭。模型热启动呈灰色时，先开启常驻识别进程，才能操作热启动开关。

如果仅偶尔识别文字，可以关闭常驻与热启动；频繁识别时再测试它们的收益。每次只调整一个选项，重新发起几次识别，比较首次与后续等待。出现硬件加速异常时可关闭该项，再用新识别任务检查 CPU 路径能否正常完成。

## 本地 OCR 与在线能力的界限

本地文字识别完成后，即使没有网络也能整理和复制文字。点击**文本翻译**、表格识别的在线服务或视觉模型、公式识别、图片转换时，需要分别满足对应服务条件。不要把“文字已经识别成功”当成这些在线服务已经就绪。
