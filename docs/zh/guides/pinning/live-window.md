# 实时窗口贴图

**固定窗口到屏幕**把来源窗口的内容持续显示在独立贴图里，适合一边操作、一边对照另一个窗口。它依赖原窗口继续存在；要永久保存某个状态，可以把当前帧转换为图像。

![实时窗口贴图教学示意：源窗口更新、实时贴图跟随，转换为图像后停止跟随](/images/guides/pin-live.svg)

*操作示意。实时显示、当前帧保存与录屏是三个不同结果。*

## 固定一个实时窗口

1. 先打开需要参考的窗口，把它放在屏幕可见位置。macOS 要在系统设置中授予 Snow Shot 屏幕录制所需权限；按应用权限提示完成后再尝试。
2. 使用截图快捷键（Windows 默认 **F1**，macOS 默认 **Control+1**），在目标窗口内容区域建立选区。选择范围应对应一个可捕获窗口，避免中心落在桌面、工具栏空白或其他覆盖窗口上。
3. 在截图工具栏单击**固定窗口到屏幕**，等待初始化完成。它与普通的**固定到屏幕**是两个独立按钮。
4. 来源窗口内容变化时，观察实时贴图是否更新。把贴图移到合适位置，保留来源窗口继续运行。

提示“选区中未找到可捕获窗口”时，退出当前操作，把来源窗口完整显示并重新框选；提示初始化失败时，检查捕获权限和目标窗口是否仍然存在，再重试。

## 调整显示与冻结

实时贴图右键的**处理图像**提供缩放、不透明度、旋转和翻转。裁剪可用时，在贴图里右键拖出目标显示范围，再按需要选择**应用裁剪**；相关手势见[贴图变换与裁剪](./transform.mdx)。这些操作调整贴图中的观察范围，不会改变原应用窗口内的实际内容。

当右键菜单中的**转换为图像**可用时，单击它取得当前可捕获画面，窗口转成静态图片。之后可以按普通图片进行识别与标注。转换后不再跟随来源更新；想再次实时跟随，需要重新执行固定窗口到屏幕。

**复制到剪贴板**和**保存为文件**也会取得可用的当前画面，用于分享一个时刻。它们不会自动生成一段视频；需要记录连续变化应使用[屏幕录制](../recording/start.mdx)。

要在独立窗口处理一帧，可右键选择 **处理图像 → 图像编辑** 或 **处理图像 → 图像分割**。它们把取得的当前帧交给对应窗口，实时贴图仍继续跟随来源；到新窗口检查输入，再按[图像编辑](../image-editing/editor.mdx)或[图片分割](../image-editing/split.mdx)完成并保存。只有**转换为图像**会把这张实时贴图本身改为静态图。

画面暂时不可用时，复制、保存、转换为图像、图像编辑、图像分割等需要当前帧的命令可能不可用。先恢复来源窗口，再尝试。

## 画面停止更新时

| 显示状态 | 原因与处理 |
|---|---|
| 窗口已最小化，无法显示最新内容 | 恢复来源窗口，等待实时内容重新出现；不要把旧帧当成当前状态 |
| 窗口已关闭，无法显示最新内容 | 原窗口已经结束。重新打开应用后要重新选定窗口建立贴图 |
| 实时内容不可用，正在重试 | 等待自动重试；检查目标是否可见、权限是否仍有效，必要时关闭此实时贴图并重新建立 |
| 准备图像时窗口发生变化，请重试 | 复制或转换期间来源改变；等画面稳定后重新执行命令 |

实时窗口菜单不会提供普通图片的全部功能，例如加载新的剪贴板内容、缩略图、顶部隐藏和静态画布标注。需要这些普通图片操作时先转换为图像。

实时来源关闭或应用退出后，不能把管理页里的静态图像恢复能力理解为会自动重新连接原窗口。重要状态应主动复制或保存。
