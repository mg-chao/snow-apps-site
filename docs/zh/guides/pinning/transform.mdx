# 贴图变换与裁剪

贴图可以缩放、旋转和变成半透明，方便叠在设计稿或其他窗口旁边对照。裁剪分为**收窄当前显示范围**和**应用裁剪**两步，先明确自己只想临时少看一部分，还是要把当前贴图内容裁掉。

![贴图变换教学示意：原图、旋转结果、半透明叠加与裁剪范围](/images/guides/pin-transform.svg)

*操作示意。显示比例和窗口透明度不等于改写源文件。*

## 缩放与定位

在贴图上右键，进入**处理图像 → 缩放**。直接选 **25%、50%、75%、100%**，或用**增加 10%**、**减少 10%**逐步调整；菜单里的“当前”一项用于查看现有比例。

普通图片模式中，指针放在贴图上滚动也能调整显示比例。若已经进入文字识别或标注模式，滚轮可能用于该模式中的内容操作；要调整整体贴图，先回到普通图像模式，或明确使用右键菜单。

在**设置 → 固定到屏幕**可设置滚轮缩放步长和固定点：鼠标位置、四个角或中心点。希望对准细节时选择鼠标位置，希望边缘不漂移时选择相应角。调整设置后用一个明显角点验证缩放位置。

## 半透明与旋转翻转

**处理图像 → 不透明度**提供 **25%、50%、75%、100%** 和增减 10% 操作。先选 50% 观察叠加效果，恢复 100% 可以正常阅读。窗口透明度与保存图像的内容不同，不应把“屏幕上半透明”当作文件已经带有透明背景。

在**处理图像**中，**顺时针旋转**与**逆时针旋转**每次改变 90°；**水平翻转**、**垂直翻转**改变图像方向。使用**重置变换**恢复旋转、翻转方向。缩放和不透明度有各自的菜单值，不能用重置变换代替设置它们。

## 裁剪贴图

右键**单击**打开菜单，右键**拖动**则用来选择裁剪视图。这两个手势的结果不同。

1. 先退出标注、文本识别、锁定、鼠标穿透、缩略图和顶部隐藏状态，回到普通贴图。
2. 在图像内部按住**鼠标右键**，从要保留范围的一角拖到对角；拖动时观察矩形范围。还未松手时按 **Esc** 可取消本次手势。
3. 松开右键后，窗口收窄到所选可见范围。过小的拖动会按右键菜单处理，所以要拖出明显的矩形。
4. 如果确定要把当前贴图内容裁到这个范围，再右键选择**应用裁剪**，等待图像处理结束。保留原始资料有需要时，应用前先复制原始内容或另存一份。

应用后，当前贴图的图像内容只保留选定范围。裁错时，可通过**加载新内容**重新载入原文件或原始剪贴板内容。裁剪不会直接覆写最初的源文件；之后保存时选择新文件名，可以同时保留原图和裁剪结果。

## 边框与阴影

在贴图右键的**固定到屏幕管理**中，**显示边框**与**显示阴影**切换当前窗口的装饰。先打开一张浅色图片，切换一次观察轮廓，再按需要保留；这些是窗口显示装饰，不是用形状工具画进图片的边框。

新窗口的默认外观在**设置 → 固定到屏幕 → 窗口界面**调整：

| 设置 | 操作后检查 |
|---|---|
| 默认显示边框 | 新建一张贴图，确认初始边框显示状态；已有窗口可从自己的菜单切换 |
| 默认显示阴影 | 新建一张贴图，检查初始阴影 |
| 边框颜色、阴影颜色 | 调整普通状态下窗口边缘和投影的颜色 |
| 边框激活颜色、阴影激活颜色 | 点击贴图使其获得焦点，检查激活时的边缘区别 |
| 锁定边框颜色、锁定阴影颜色 | 开启锁定模式，检查锁定状态的边缘提示 |

![贴图装饰教学示意：普通、获得焦点与锁定状态使用不同边框或阴影颜色，新建默认与当前窗口菜单分别控制](/images/guides/pin-border.svg)

*操作示意。图中颜色用于区分状态，不代表应用默认配色。*

同一设置页中的**自动调整窗口大小**用于让滚动长截图等新贴图保持在显示器范围内。开启后用一张长图创建贴图，检查初始窗口是否适合当前屏幕；需要查看细节时再缩放或调整显示范围，它不会把源图的像素内容删掉。

## 防止遮挡与误操作

| 模式 | 进入与退出 | 使用效果 |
|---|---|---|
| 鼠标穿透 | 右键**鼠标穿透**；启用后使用独立的**退出鼠标穿透模式**按钮退出 | 大部分图像区域的鼠标操作交给后面的应用；辅助控件仍可操作 |
| 锁定模式 | 右键勾选或取消**锁定模式** | 防止意外移动、缩放或裁剪；调整前先解锁 |
| 缩略图模式 | 右键勾选或取消**缩略图模式** | 临时缩小普通贴图以腾出工作区 |
| 顶部隐藏 | 右键启用**顶部隐藏**；指向顶部句柄查看，再取消菜单中的该模式退出 | 把普通贴图收在屏幕顶部，需要时再展开 |

鼠标穿透启用后，不能再依靠图像本身的右键进入普通菜单，应先找辅助退出按钮。要隐藏大量窗口，可以使用[分组和批量操作](./management.mdx)。实时窗口只提供其支持的模式，不能套用普通贴图的全部管理项。

双击和鼠标中键的行为可以在设置中分别配置，例如重置缩放、缩略图、顶部隐藏、显示识别结果、关闭或销毁。不要把其他用户的双击行为当作固定快捷手势。
