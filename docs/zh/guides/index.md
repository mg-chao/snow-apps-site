# Snow Shot 截图与文本识别使用指南

Snow Shot 是面向 Windows 和 macOS 的免费开源截图、录屏工具。
完整使用文档与源码一起在**官方 GitHub 仓库**维护，便于随功能变化及时更新。

## 安装并完成第一张截图

根据处理器架构选择安装包，学习框选、标注、复制和保存。
快速上手指南还说明完整版与 Mini 的区别、默认快捷键、macOS 权限和截图历史。

[在 GitHub 阅读快速上手指南](https://github.com/mg-chao/snow-apps/blob/main/docs/guide/zh-CN/getting-started.md)
· [选择下载版本](/zh/download.html)

## 截取滚动长截图

保存一屏放不下的网页、聊天记录等内容。
指南说明如何选择滚动区域、检查拼接预览，以及处理固定页头、动态内容和重复行。

[在 GitHub 阅读滚动长截图指南](https://github.com/mg-chao/snow-apps/blob/main/docs/guide/zh-CN/scrolling-screenshots.md)

## 使用离线文本识别提取文字

安装所需资源后，标准文本识别在本机运行。
指南说明离线环境准备、识别质量、完整版与 Mini 的区别，以及在线翻译为何有独立网络要求。

[在 GitHub 阅读离线文本识别指南](https://github.com/mg-chao/snow-apps/blob/main/docs/guide/zh-CN/offline-ocr.md)

## 将资料贴到屏幕，或录制操作演示

使用贴图把参考图片放在其他窗口上方，或通过录屏展示连续操作。
指南介绍剪贴板贴图、音频选择、权限和导出结果检查。

[在 GitHub 阅读贴图与录屏指南](https://github.com/mg-chao/snow-apps/blob/main/docs/guide/zh-CN/pin-and-record.md)
