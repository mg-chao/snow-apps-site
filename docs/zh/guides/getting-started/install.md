# 安装与更新

从[官网下载页](/zh/download.html)选择适合电脑的安装包。首次使用且希望使用完整识别功能时，选择完整版；更在意安装体积时，可选择 Mini，再按需准备组件。

![Windows x64、ARM64 与两种 Mac 架构的安装包选择示意](/images/guides/start-install.svg)

*操作示意：先确认系统与处理器，再选择完整版或 Mini。*

<span id="选对系统架构和版本"></span>

## 选择系统、处理器与安装包

1. Windows 在系统设置中查看系统类型；Mac 打开苹果菜单“关于本机”，查看芯片或处理器。
2. 回到下载页，选择 **Windows** 或 **macOS**，再选择匹配的处理器。Apple 芯片使用 `arm64`；Intel Mac 使用 `x86_64` 完整版。macOS 要求 **15 或更新版本**。
3. 选择完整版或 Mini。下载按钮会随平台、架构和应用选择改变，下载前再看一次文件名，避免把 Windows ARM64 与 x64 混用。

| 需求 | 选择 |
| --- | --- |
| Windows 常规安装 | 与处理器匹配的在线安装包 |
| Windows 无网络环境 | 完整版离线安装包，包含默认 OCR 资源 |
| Windows 无需安装向导 | 完整解压便携包后运行，不要只从压缩包中拖出主程序 |
| Apple 芯片 Mac | 完整版或 Mini 的 `macos-arm64.dmg` |
| Intel Mac | 完整版 `macos-x86_64.dmg` |

Mini 不提供 Intel Mac 版或 Windows 离线包。Mini 的文本识别可以通过添加工具栏入口或绑定识别动作使用，表格、条码、公式、图片转换及翻译等完整版与 Mini 的功能有所不同；具体入口和资源准备见[识别模型与离线资源](../recognition/models.md)。不要把“组件首次下载后可离线识别”理解为“所有服务均可离线”。

## 安装并首次启动

Windows 使用安装包时，按向导选择目录并完成安装；使用便携包时，将整套文件解压到可写目录，再运行 Snow Shot。若通过系统应用商店或包管理器安装，保留对应渠道，之后从同一渠道更新。

Mac 打开 DMG，将 Snow Shot 拖到“应用程序”，再从“应用程序”启动。首次截屏可能出现系统权限引导，按[macOS 权限](./permissions.md)处理；在权限授予后按提示重新启动应用，再测试截图。

启动后可从系统托盘或 macOS 菜单栏图标打开主窗口。新配置的截图默认键为 Windows **F1**、macOS **Control+1**；使用 Mac 键盘上的 Control 键，不是 Command 键。Windows 部分键盘需要 **Fn+F1**。已有配置可能保留其他绑定，没有反应时在主窗口的 **全局快捷键** 查看“截图”动作及注册状态，并按[快捷键排查](../settings/shortcuts.mdx)处理。

## 语言、启动与更新

打开 **设置 → 常规**：

- 在 **语言** 中选择简体中文或其他语言，界面文字会随语言设置更新。
- 在 **启动与更新** 区域设置登录时启动。macOS 如被系统关闭登录项，还需在系统设置的登录项中检查 Snow Shot。
- 在 **更新** 选择更新方式。**手动** 由你主动检查；**自动检查** 会检查新版本。Windows 还提供 **自动下载** 与 **下次启动时自动更新**；macOS 不提供这两种自动安装方式，发现新版后下载并替换应用。

查看更新提示中的版本号和安装渠道，再执行对应操作。官网下载版可通过更新提示或[下载页](/zh/download.html)获取新版；应用商店、包管理器安装应使用相应渠道更新。更新前先完成当前截图和录制，避免把尚未导出的编辑结果留在待关闭窗口中。

## 安装或更新遇到问题

**程序与系统不兼容。** 先核对架构及 macOS 最低版本，再下载匹配的安装包。Mini 的体积差异不会改变系统要求。

**离线时识别要求下载。** 安装包、OCR 模型和录屏组件是不同资源。联网准备所需资源后再断网测试；具体见[模型与离线准备](../recognition/models.md)和[录屏准备](../recording/start.mdx)。

**版本号没有改变。** 确认启动的是替换后的应用，并退出旧进程后重新打开。便携目录、安装目录和 Mac DMG 内的应用可能同时存在，避免启动旧副本。
