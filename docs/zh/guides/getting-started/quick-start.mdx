# 完成第一张截图

先打开准备截取的应用，让目标内容完整显示在屏幕上。第一次练习可以使用一段不含隐私的文字或网页。Mac 首次截图先完成[权限设置](./permissions.md)。

![Snow Shot 在 macOS 的主窗口，截图动作位于全局快捷键页](/images/guides/start-main-interface-macos.webp)

*图中显示这台电脑的快捷键配置。自定义按键以自己的设置为准。*

## 框选要保留的画面

1. 启动 Snow Shot，按截图快捷键：新配置默认 Windows **F1**、macOS **Control+1**。画面进入截图状态，指针附近会出现放大取色和坐标提示。Windows 部分键盘需要按 **Fn+F1**；自定义过按键时以主窗口「全局快捷键」显示为准。
2. 把指针放在目标区域左上角，按住左键，拖到右下角，再松开。明亮区域是将要保留的选区，选区旁出现截图工具栏。
3. 如果范围不对，先切换 **移动**，拖选区内部调整位置，拖边框或角点调整大小。想精确输入尺寸，单击选区尺寸数字，见[精确选区](../capture/precise-selection.md)。

## 加上说明并修正

1. 点击截图工具栏的 **箭头**，在样式条选择 **直线箭头**。从说明所在位置拖向要指出的目标，松开左键后箭头保留在画布上。
2. 点击 **文本**，在画面中单击放置位置，输入简短说明，再按 **Esc** 完成输入。文字会留在画面中；此时可切换工具继续标注。
3. 画错时点击 **撤销**；需要移动某个标注时切换 **选择元素**，单击该对象，看到控制点后再拖动。拖选区和拖标注使用不同工具，不要把移动画面范围误当成移动箭头。

箭头的弯曲、端点符号和后续编辑见[箭头教程](../annotations/arrows.mdx)；文字字号、描边和排版见[文字标注](../annotations/text.mdx)。

## 选择结果去向

| 想做什么 | 在工具栏执行 | 接下来检查 |
| --- | --- | --- |
| 发到聊天或文档 | **复制到剪贴板**，然后到目标应用粘贴 | 粘贴得到的图片包含选区内标注 |
| 保留本地文件 | **保存为文件**，选择路径与格式，再确认保存 | 打开文件查看内容和边缘 |
| 作为桌面参考 | **固定到屏幕** | 图片成为浮在其他窗口上的贴图 |
| 直接放弃 | **取消截图** 或 Esc | 截图界面退出，不导出这次结果 |

若只想框选后直接复制，可从 **复制到剪贴板** 的全局动作进入，默认 Windows **Ctrl+F1**、macOS **Control+2**。此入口选区确定后执行复制，和进入完整编辑工具栏的普通截图工作流不同。

## 第一次使用时的排查顺序

按键没有反应，先确认 Snow Shot 正在运行，再检查 Fn、按键冲突和全局快捷键状态。进入截图但画面异常，Mac 先检查屏幕录制权限；Windows 可在截图设置中检查捕获方式，详见[基础截图](../capture/basics.mdx)。

需要重新使用以前的画面，从[截图历史](../output/history.md)打开；历史与导出文件是独立的保存对象，删除导出图片并不等于清理历史。
