# 文本翻译

有可以直接复制的文字时，在主界面的**翻译**页输入或粘贴即可，不必先截图。输入和语言设置发生变化后会自动重新翻译。该页面需要完整版，并且要先启用翻译扩展。

![文本翻译教学示意：指定源语言目标语言及服务，输入后等待，最后复制译文](/images/guides/tr-text.svg)

*操作示意。原文可以修改，译文区域用于阅读、选择和复制。*

## 打开翻译页面

1. 在主界面打开**设置 → 文本识别与翻译 → 翻译扩展**。
2. 开启**翻译页面**，返回主界面后从侧栏进入**翻译**。该开关同时启用“翻译选中文本”快捷动作，初始配置默认关闭。
3. 需要从截图识别结果进入时，再开启**跳转到翻译页面**。之后文本识别属性栏会提供同名按钮，用来把识别文字送到翻译页。

如果找不到页面，先确认已开启上述总开关，并且使用的是完整版。单独配置翻译服务不会自动开启这个页面；Mini 不包含此扩展。

## 输入与切换语言

1. 在页面上方的**源语言**、**目标语言**和**翻译服务**中选好需要的组合。不确定源语言时选择**自动检测语言**。
2. 在**原文**区域粘贴或输入完整语句。停止输入后等待，译文区域会显示处理状态并更新结果；不需要再寻找一个“开始翻译”按钮。
3. 修改原文中的错误、换一个目标语言或服务时，应用会重新处理。等待当前结果更新，再与原文对照，避免把上一轮结果当作新译文。
4. 若需要反向翻译，先明确指定源语言，再使用**交换语言**。源语言是自动检测或两端语言相同时，交换按钮不可用。

输入法仍在组合文字时，先完成候选词输入，再观察译文；持续输入会推迟当前这轮请求。译文区域是结果展示区，需要改写时修改原文后重新翻译，或复制到自己的编辑器继续处理。

## 复制与重试

译文出现后单击**复制译文**图标，再到目标应用粘贴。想只复制一部分，可先在原文或译文中选择文字，再使用通常的复制操作；存在文本选择时保留普通复制范围，没有选择时页面快捷复制会取得完整译文。

独立翻译窗口的翻译操作菜单提供**复制**和**复制并关闭**，菜单会显示当前平台的快捷键。复制并关闭会把译文放入剪贴板并关闭独立窗口；需要继续比较多个服务时先保持窗口打开。

出错时阅读译文区域的错误提示，检查服务配置和网络后单击**重试**。重新输入、改变语言或更换服务也会启动新一轮处理；不要在错误还没解决时反复清空长篇原文。

主界面翻译页关闭或离开后，当前会话内容可能被清空。需要保留的原文与译文应先复制到文档。
