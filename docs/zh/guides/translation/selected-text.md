# 划词翻译

**翻译选中文本**把其他应用里已经选中的文字送进 Snow Shot，适合阅读浏览器或文档时快速查译。它读取的是文本选择；图片中无法选中的字应使用[截图翻译](./screenshot.md)。此功能在完整版提供。

![划词翻译教学示意：在外部应用保留文字选择，调用动作后进入主界面或独立窗口](/images/guides/tr-selected.svg)

*操作示意。取词与翻译是连续的两步，取词成功后仍需可用翻译服务。*

## 启用划词入口

1. 打开**设置 → 文本识别与翻译 → 翻译扩展**，开启**翻译页面**。这个开关同时控制翻译页和划词动作是否启用。
2. 到**设置 → 全局快捷键**找到**翻译选中文本**，设置一个不与其他程序冲突的组合，并记下设置页显示的按键。
3. 返回一个有可选择文字的应用，拖选一段普通文本，再使用刚设置的快捷动作测试。先用短句，确认取词和服务都正常后再处理更长内容。

## 翻译选中的文字

在外部应用里拖动选择整句，**保持该应用当前的文字选择**，直接按划词快捷键。不要先点击 Snow Shot 主窗口，否则原应用可能失去选区。

取到的文字会出现在翻译页或独立窗口的原文区域，随后自动翻译。先核对原文是否完整，再看译文；漏掉半句时返回来源应用重新选择，或手动复制完整文本并粘贴到翻译页。

可以在目的页面切换目标语言和翻译服务，修改原文后重新处理。结果出现后单击**复制译文**，或在文字中选择所需部分复制。

## 选择独立窗口

在**文本识别与翻译 → 翻译扩展**开启**独立翻译窗口**后，划词结果进入单独的翻译窗口；关闭此项则进入主界面翻译页。独立窗口仍依赖“翻译页面”总开关。

独立窗口的翻译操作菜单有**复制**和**复制并关闭**。先确认译文，再使用复制并关闭回到阅读应用。关闭窗口前要保留的内容应先复制。

## 取不到文字时

macOS 的原生取词会先尝试辅助功能读取，在适用条件下使用剪贴板回退。到系统设置为 Snow Shot 授予所需**辅助功能**权限，再回到原应用重新选择；授权成功仍不保证所有应用都公开它们的文本选择。

其他平台的取词路径会尝试剪贴板读取，来源应用需要响应普通文本复制。受保护输入框、特殊画布、没有真实文字选区的图片都可能取不到内容。

| 现象 | 可执行的处理 |
|---|---|
| 翻译窗口打开，但原文为空 | 回到来源应用重新选择短句，保持焦点后再调用；或手动复制粘贴 |
| 读到了不完整内容 | 检查原应用的选择范围，避免选区跨越无法复制的控件 |
| 取到了文字，但没有译文 | 取词已完成；检查翻译服务、网络或模型错误，再点击**重试** |
| 快捷键没有响应 | 检查翻译页面总开关和快捷键绑定，换一个没有冲突的组合 |
| 屏幕上只有图片中的文字 | 改用截图翻译，不需要强行在图片上建立文字选择 |
