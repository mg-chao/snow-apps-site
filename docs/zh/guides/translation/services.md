# 翻译服务与自定义模型

Snow Shot 的翻译服务和自定义 AI 模型在**设置 → 网络与连接**集中配置。专用翻译端点用于翻译文字；支持图片输入的视觉模型还可用于图片转换、表格与公式相关任务。先准备服务提供方给出的地址、认证信息和模型 ID。

![服务配置教学示意：专用翻译使用完整端点，自定义模型使用基础地址并选择实际模型](/images/guides/tr-services.svg)

*操作示意。两类地址的填写规则不同，不能互相套用。*

## 添加专用翻译配置

1. 进入**设置 → 网络与连接 → 翻译服务**，在**翻译配置**中单击**添加配置**。
2. 填写便于辨认的**配置名称**，在**服务格式**选择 **DeepL**、**DeepLX**、**百度**或**有道**。服务格式决定请求协议，要与真实端点对应。
3. 在 **API URL** 填写服务给出的**完整翻译端点**；服务要求路径或查询参数时一并保留，应用不会自动补出接口路径。不要从服务主页域名猜测端点，也不要把账号密码嵌在 URL 中，或附加 `#` 片段。
4. DeepL / DeepLX 按服务要求填写 **API 密钥**；DeepLX 的可选令牌作为 Bearer 令牌发送。百度、有道使用对应的**应用 ID**与**应用密钥**，界面会按服务类型显示所需字段。
5. 设置**并发数**，范围为 **1–16**。这是该配置跨翻译任务允许的同时请求数；服务限流时应降低，而不是持续增大。
6. 单击**保存**。配置出现在列表中后，回到翻译页，在**翻译服务**里选择它，用一句短文本确认实际请求能成功。

## 添加自定义模型

1. 在**网络与连接 → 自定义 AI 模型**的**自定义模型**区域单击**添加模型**。
2. **模型名称**填写显示名称；**API URL**填写 OpenAI 兼容 Chat Completions 的**基础地址**。应用会追加 `/chat/completions`，不要把这段路径重复写入基础地址。
3. 填写 **API 密钥**与 **API 模型**。模型字段可以直接输入服务给出的精确 ID，也可以展开列表尝试获取；列表获取失败时，仍可手动输入 ID。
4. 按真实能力设置**视觉支持**。只有远端模型确实接受图片输入时才启用；这个开关不会为纯文本模型增加识图能力。
5. 选择**服务商类型**（OpenAI、Qwen、DeepSeek、Doubao），让推理控制方式与接口对应。OpenAI 类型的推理由模型控制，此时**推理支持**开关不可用；其他类型可按界面选项显式设置推理支持。
6. 设置 **1–16** 的**并发数**，单击**保存**。回到翻译页选择模型测试文字；再在图片转换工具中测试图像能力。

**基础地址校验**要求 HTTP 或 HTTPS，不接受嵌入凭据、查询或片段；密钥不能包含换行。名称不能与已有配置重名。先修正字段旁的提示，再保存。

## 修改配置与排查连接

1. 在目标配置行点击**编辑**，修改字段后点**保存**；点**取消**关闭表单，不保存这份编辑草稿。
2. 点击**复制**会直接新增带复制后缀的独立项，沿用原项的地址、凭据和选项，不会先打开编辑表单。找到副本后再点编辑，改成需要的配置并保存；回到翻译任务选择要使用的那一项。
3. 点击**删除**后，先核对确认窗口中的名称。点取消保留它，确认删除才移除；正在使用的项被删后会改用其他可用选择，回到任务重新确认服务并重试。删除失败时先处理提示的问题，再尝试。

| 出现的问题 | 检查顺序 |
|---|---|
| 保存失败或配置没有留在列表中 | 先读字段校验，再检查配置存储是否可写；重新打开表单确认，而不是直接开始网络任务 |
| 模型列表取不到 | 检查基础地址与认证，重新展开模型列表可再尝试获取；也可手动输入已知模型 ID，再用短句测试 |
| 翻译认证失败 | 核对服务格式、密钥、应用 ID，清除粘贴时的多余换行或空格 |
| 图像任务拒绝输入 | 核对真实模型是否支持图片、已启用视觉支持、图片格式和接口是否兼容 |
| 请求超时或无法连接 | 检查**网络代理**、端点地址和本地服务是否运行；修正后回原任务使用**重试** |
| 修改配置后旧任务仍提示错误 | 按提示重试，让新任务使用更新后的配置 |

**Snow Shot 服务端**中的服务器地址作用于内置在线服务，清空可回到默认地址；它与某个自定义模型的 API URL 分开设置。修改服务器地址不会修改应用更新来源。

此页配置能力属于完整版；Mini 中没有相应翻译和 API 配置入口。
