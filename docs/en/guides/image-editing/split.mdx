# Split images and edit cut lines

Image splitting cuts one long or large image into separate files. Smart splitting finds likely boundaries; equal and precise splitting create lines from counts or dimensions. Inspect every result before exporting.

## Import and create a split

1. Search **Split selected images** in the main window's **Search function**, select the result, and click the action row to open **Image splitting**. Click **Select image** or drag in one image file. Each window handles one image.
2. Wait for the image, then choose **Split direction**: **Vertical** makes vertical cuts and left/right pieces; **Horizontal** makes horizontal cuts and top/bottom pieces; **Grid** cuts both axes. For a long article, start with Horizontal and divide at blank lines.
3. With Vertical or Horizontal selected, choose **Smart split**, **Equal split**, or **Precise split** under **Split type**. Smart split shows a search state before its lines appear. Grid hides Split type and uses row and column counts directly.
4. Check the image count and cut positions. Zoom in to ensure no line crosses essential text or objects.
5. Adjust lines, click **Save all**, select a destination folder, and wait for every image to save.

## Paste from the clipboard or replace the image

1. Open the original in an image viewer and copy its image content. Return to Image splitting, finish editing numeric or text fields, then click the preview; in an empty window, click the image-selection area first. Press **Ctrl+V (Command+V on macOS)** and wait for the image.
2. When the clipboard provides readable local image file paths, only the first supported image is loaded. The list does not create one window per file. If that first image cannot be read, correct the input and retry.
3. With an image already open, wait for the new image to load, then review the replacement confirmation. **Cancel** retains the original and current splits. Accepting loads the new image and resets old cut edits and undo history. Save the old result first if needed.
4. Check the content and dimensions at the bottom, then inspect the new cut lines. If a file icon appears, use **Select image**, drag in the original file, or copy image content from a viewer before pasting again.

## Start from selected files

Find **Split selected images** under **Global shortcuts** and assign a nonconflicting combination. There is no preset binding; the screenshot shortcut does not substitute for it. Return to the file manager, select one or more images, and invoke the action. Each image opens in a separate splitting window.

With no images selected, an empty window opens where you can add one. On macOS, follow any request for Finder Automation access and retry. See [Shortcut settings](../settings/shortcuts.mdx).

## Split by content, count, or dimensions

| Mode | Input or basis | Suitable use |
| --- | --- | --- |
| Smart split | Target image count, image content, and whitespace | Set a positive whole-number count, find likely boundaries, then inspect them |
| Equal split | A positive whole-number image count | Similarly sized pieces along the selected direction; sizes can differ by 1 px |
| Precise split | Width per image for Vertical; Height per image for Horizontal | Repeated lengths in pixels or percentages of that source dimension |
| Grid | Positive whole-number row and column counts; no separate split type | Rows × columns images, output in row-major order |

Precise **Pixels** accepts whole numbers of at least **16 px**. **Percentage** accepts **5%–100%** of the source width or height, not its displayed preview size. The last piece retains the remaining pixels and may be shorter; 100% produces one piece. Equal counts and grid dimensions must leave at least 1 px per piece on each axis. Resolve field errors before checking the preview.

## Correct cut lines with rulers

1. Click a target position on the top ruler to add a vertical cut, or on the left ruler for a horizontal cut. Only cuts allowed by the current direction can be added; Grid allows both.
2. Hold the left button on an existing line and drag while watching its coordinate. Avoid text and object centers, then release to apply. Press **Esc before releasing** to restore its position before the drag.
3. Click a line to select it and press **Delete / Backspace** to remove it.
4. Middle-drag to pan and scroll to zoom. Click **Fit to canvas** to regain the full view.

Retain sensible smart-generated lines and add or move others. Automatic results still require checking.

## Overlap and undo

**Overlap width** accepts nonnegative whole pixels. Each slice extends that far past each cut, clipped to the source edges. At 10 px, the two neighboring slices each gain 10 px past the cut, normally sharing a 20 px band. Grid extends both axes. Zero adds no overlap; changing overlap does not move your manual cut lines.

Use **Undo / Redo** after cut-line edits. **Reload** opens image selection to reselect or replace the source. Decide whether you need to retain manual edits first. Replacing prompts that current splitting edits will be discarded; read it before confirming.

## Save or create a PDF

Click **Save all** and choose a parent folder. Snow Shot creates a subfolder beginning with **Split Images_** and writes **1.png, 2.png**, and so on. Progress shows “Saving images: completed / total.” After saving, open the parent folder you chose in your file manager, then enter the newly created subfolder. Check the file count, order, and content near each cut.

For partial saving, inspect failures and existing files before retrying. A retry uses a new output subfolder; do not combine partial batches and assume they form one complete set. Closing or clicking **Cancel** asks whether to discard the current splits; cancel that prompt to continue editing.

Click **Stitch to PDF** to send slices into PDF layout. Check page order and paper in the new preview before exporting; see [Images to PDF](./pdf.mdx). If image stitching is busy, wait for its current task and retry.
