# Filters, mosaic and automatic filtering

Filters process local image areas. Mosaic and Gaussian blur commonly obscure detail; grayscale, inversion, emboss and brightness change appearance. Check the screenshot region, then choose **Filter** in the annotation toolbar.

## Apply mosaic to an area

1. Expand Filter, choose **Rectangle filter** and select **Mosaic** in **Filter type**.
2. Hold the left mouse button at one corner, drag to the opposite corner, inspect the coverage and release.
3. Keep Rectangle filter active and click the created region to select it. Adjust **Filter intensity** and check whether detail remains recognizable. To change blending with the source, switch to **Select elements**, select the filter again and adjust **Opacity** in the general selection toolbar.
4. Use Select elements and handles to correct its boundaries, leaving no unintended gaps.
5. Deselect, enlarge the view to inspect edges and output bounds, then copy or save.

To change an existing rectangle or brush filter’s type or intensity, return to its matching tool and select the range: left-click a rectangle, or right-click a brush range while idle by default. **Select elements** provides general transforms, stacking and opacity. Switching drawing tools clears the previous selection, so select the object again.

## Rectangle and brush ranges

**Rectangle filter** suits regular areas. **Brush filter** follows the pointer while the mouse button is held and finishes on release. Set brush width first: narrow for small details, wider for larger areas.

Return to the matching Rectangle or Brush filter tool to edit an existing filter. Click rectangle filters with the left button. Brush filter disables left-click quick selection by default: right-click an existing range while idle, or remove it from **Tools that forbid quick selection of same-type elements** before using left-click selection. Select the object before changing type or intensity. For opacity, switch to Select elements and select the range again. Add a stroke for missed coverage; if too much was covered, undo and redraw with a narrower brush. Use Rectangle filter for precise right-angle boundaries.

## Compare effects

| Type | Result | What to inspect |
| --- | --- | --- |
| Mosaic | Reduce detail with color blocks | Sufficient intensity and coverage |
| Gaussian blur | Smooth local detail | Whether text and edges remain recognizable |
| Grayscale | Remove local color | Accurate coverage |
| Inversion | Reverse colors | A visual effect, unsuitable for hiding information |
| Emboss | Emphasize light/dark edges | Detail and bounds |
| Brightness | Change local lightness | Actual brightness at the chosen intensity |
| Smart erase | Reconstruct covered content from surrounding image areas | Continuous texture and remaining traces |

### Remove source-image content with Smart erase

1. With an image loaded in the editable canvas, choose **Filter → Rectangle filter → Filter type → Smart erase**. Brush filter also provides it for irregular ranges; Auto filter does not.
2. Drag a small range over the source content, then release. The red translucent overlay during dragging previews the range; reconstruction starts after release. You do not need to select source-image text with Select elements.
3. Wait until the red overlay is replaced by the reconstructed image, then check removal and edge continuity. **Filter intensity** is disabled for this type; increasing intensity cannot improve reconstruction.
4. If unsuitable, undo and redraw a smaller range with more surrounding background available. Moving or resizing an existing range recomputes the result. Wait for completion before copying or saving.

Inspect complex text, repeated textures and large areas individually. A persistent red overlay is not a completed result. Undo and retry a smaller area, or use manual mosaic or blur coverage.

### Intensity behaves differently for different filters

Higher mosaic intensity generally creates larger blocks; stronger Gaussian blur removes more detail. **Grayscale and inversion do not change with the intensity slider**. Adjust selected-object opacity to blend them with the original.

**Brightness** is unchanged at 50%, darker below it and lighter above it. Do not interpret 0% as no effect. Emboss intensity changes edge contrast.

## Detect regions, then fill

**Auto filter** detects image regions before you choose what to process, useful for handling text, avatars or image blocks in batches.

1. With an image loaded, choose **Auto filter**. Wait for the scanning band to finish. Detected regions flash red briefly; move over content to inspect its range afterward.
2. Choose filter type and intensity, then left-click a detected region and release to apply it. Clicking a region that already has the same filter type removes its effect; clicking after choosing a different type replaces it.
3. For a whole category, open **Fill regions** and choose **Text**, **Text in box**, **Image**, **Avatar**, **Icon**, **Message box** or **Text block**. This applies the current type and intensity to that category. Adjust intensity and fill the same category again to update it.
4. Inspect every area afterward. Use Rectangle or Brush filter for missed content; Undo unwanted effects.

*Choose one category to fill it immediately, then reopen the menu for another category. <a href="/images/guides/en/ann-filter-category-menu.svg" target="_blank" rel="noreferrer">Enlarge the category menu</a>.*

You can also hold the left button and drag a marquee. Detected regions **intersecting** it are affected; full containment is unnecessary. Automatic detection can miss sensitive information, so inspect every area. With no available regions, **Fill regions** is disabled; use manual ranges instead.

### Retry detection after failure

If **Region identification failed. Try auto filter again** appears, confirm the image has loaded, switch to **Rectangle filter**, then back to **Auto filter** to start detection again. There is no separate Retry button. If it still fails, use manual ranges rather than only waiting for the category menu.

## Inspect and correct the result

Intensity alone cannot fix missed edges. Correct coverage before adjusting the effect. Low opacity reveals the source beneath. For complete solid coverage, use a filled shape and inspect the exported image.

Editable filters can be undone or deleted. Reopening an exported picture gives flattened pixels. Related: [Erasers](./eraser.mdx) · [Shapes](./shapes.mdx) · [Element editing](./elements.mdx).
