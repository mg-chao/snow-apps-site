# Snow Shot screenshot and text recognition guides

Snow Shot is a free, open-source screenshot and screen recording tool for Windows
and macOS. The **official GitHub repository** maintains the full user guides
alongside the app's source code, so instructions can be updated with its features.

## Install and take your first screenshot

Choose a package for your processor, then learn how to capture, annotate, copy and
save a selection. The guide explains the full edition and Mini, default shortcuts,
macOS permissions, and screenshot history.

[Read the getting started guide on GitHub](https://github.com/mg-chao/snow-apps/blob/main/docs/guide/getting-started.md)
· [Choose a download](/download.html)

## Take a scrolling screenshot

Capture content longer than one screen, such as a webpage or conversation.
Learn how to select the scrolling region, inspect the stitched preview, and
troubleshoot fixed headers, moving content and repeated rows.

[Read the scrolling screenshot guide on GitHub](https://github.com/mg-chao/snow-apps/blob/main/docs/guide/scrolling-screenshots.md)

## Extract text with offline text recognition

Standard text recognition runs on your device once the necessary resources are installed.
The guide explains offline preparation, recognition quality, full/Mini differences,
and why online translation has separate network requirements.

[Read the offline text recognition guide on GitHub](https://github.com/mg-chao/snow-apps/blob/main/docs/guide/offline-ocr.md)

## Pin a reference or record a demonstration

Keep images above other windows while you work, or record a sequence of actions.
Learn about clipboard pinning, audio selection, permissions and reviewing exports.

[Read the pinning and recording guide on GitHub](https://github.com/mg-chao/snow-apps/blob/main/docs/guide/pin-and-record.md)

## Find the official project

**mg-chao/snow-apps** is the official repository for Snow Shot. It also contains
Snow Image Viewer and shared libraries, which is why the repository is called
Snow Apps. This website, **snowshot.top**, is the official product site.
